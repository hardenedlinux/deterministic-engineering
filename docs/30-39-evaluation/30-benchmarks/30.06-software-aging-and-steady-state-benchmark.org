* Benchmark Scope and Independent Gold Policy
:PROPERTIES:
:CUSTOM_ID: bench3006-scope
:STATUS: implemented-verified
:END:

This benchmark evaluates whether a language-agnostic, multi-method engineering
gate can deterministically detect, refute, and guide AI repair of *long-running
software aging, interactive search/IME/input-sanitization stability, chaos/IPC
reconnect resilience, search-index snapshot isolation, streaming LLM/HTTP
output-budget, CI/CD scientific caching/sharding, structured async task / DB
pool cancellation hygiene, bounded subprocess pipe capture, crash-safe atomic
persistence, hostile (=ADV-L4=) sandbox symlink / manifest traversal /
archive shadowing confinement, hostile (=ADV-L4=) outbound HTTP redirect /
SSRF / cleartext remote credential / symlink static-serve confinement,
hostile (=ADV-L4=) subprocess ambient secret environment scrubbing &
constant-time non-blank Bearer auth verification, hostile (=ADV-L4=)
single-owner GraphEngine execution convergence & production-reachable
governance confinement, and hostile (=ADV-L4=) control-plane entrypoint
Bearer authentication, empty-Bearer prefix rejection, mutating RPC E-Stop
governance confinement, and scrubbed bounded release-gate shell execution
defects* (=SM1=–=SM26= in
[[file:../../40-49-research/40-reference-studies/40.04-software-aging-and-steady-state-stability.org][40.04]],
[[file:../../40-49-research/40-reference-studies/40.05-search-stability-pbt-and-structure-aware-fuzzing.org][40.05]],
and [[file:../../40-49-research/40-reference-studies/40.06-ci-cd-scientific-caching-and-subdomain-sharding.org][40.06]])
across five implementation languages (**Go, Rust, TypeScript, C, C++**) and
realistic multi-layer agent/UI architectures (**Marlin Rust/Scheme Host + MyGo
Go Bridge + WebView TS UI**) without requiring multi-hour soak runs in CI.

  property, and runtime soak/exploit assertion carries a fixed independent
  expected outcome (=pass= vs. =refuse= + exact mechanism / rule / ITF
  predicate) and MUST meet the =ADV-L3= / =ADV-L4= pressure floor (gentle
  =ADV-L1= happy-path-only suites are formally rejected in Lean 4).
