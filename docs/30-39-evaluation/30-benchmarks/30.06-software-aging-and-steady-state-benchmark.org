* Benchmark Scope and Independent Gold Policy
:PROPERTIES:
:CUSTOM_ID: bench3006-scope
:STATUS: implemented-verified
:END:

This benchmark evaluates whether a language-agnostic, multi-method engineering
gate can deterministically detect, refute, and guide AI repair of *long-running
software aging, interactive search/IME stability, and chaos/IPC reconnect
resilience defects* (=SM1=–=SM14= in
[[file:../../40-49-research/40-reference-studies/40.04-software-aging-and-steady-state-stability.org][40.04]] and
[[file:../../40-49-research/40-reference-studies/40.05-search-stability-pbt-and-structure-aware-fuzzing.org][40.05]]) across five implementation
languages (**Go, Rust, TypeScript, C, C++**) and realistic multi-layer agent/UI
architectures (**Marlin Rust/Scheme Host + MyGo Go Bridge + WebView TS UI**)
without requiring multi-hour soak runs in CI.

- *Independent Gold*: Every static case (=SA01=–=SA76=), closed-loop persona,
  formal countermodel, metamorphic search property (=MR1=–=MR6=), chaos/IME/IPC
  structure-aware fuzz property, and runtime soak assertion carries a fixed
  independent expected outcome (=pass= vs. =refuse= + exact mechanism / rule /
  ITF predicate).
- *Five Coupled Verification Layers*:
  1. *Formal Finite-State Models (Quint + Apalache 0.62.1 + 100% =--mbt=)*:
     15 stability models (36 auto-derived countermodels) + 3 UI concurrency
     kernel models (7 auto-derived countermodels) covering cyclic drain, buffer
     ratchet, metastable retry collapse, GC headroom pacing, slow-consumer
     fan-out eviction, bounded projection idle eviction & side-map cleanup,
     broadcast lag snapshot-resync & coalesced checkpoint flushing, UI bounded
     DOM viewport & $O(1)$ incremental frame budgets, interactive search query
     generation fencing & selection identity anchoring (=SM8=), single-flight
     leader cancellation safety & armed notify wakeup (=SM9=), search query
     metamorphic algebra & clipped viewport hit-testing (=SM10=),
     priority-isolated bounded mailboxes & $O(1)$ latest-wins =watch= channels
     (=SM11=), IPC half-open stream retirement + monotonic epoch fencing +
     idempotent replay (=SM12=), interactive search-box IME composition + atomic
     blur cleanup + shortcut isolation (=SM13=), and chaos fault-injection
     recovery envelopes with circuit shedding & half-open probe recovery (=SM14=).
  2. *Unbounded Algebraic Proofs (Lean 4)*:
     [[file:../../../packages/lean-models/DeterministicEngineering/Core/Stability.lean][Core/Stability.lean]]
     (Sections 1–15, zero =sorry=) proving arbitrary-cycle zero drift, ARB
