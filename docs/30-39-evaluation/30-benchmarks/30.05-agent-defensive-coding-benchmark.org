* Benchmark Scope and Independent Gold Policy
:PROPERTIES:
:CUSTOM_ID: bench3005-scope
:STATUS: implemented-verified
:END:

This benchmark evaluates whether AST-level defensive-engineering auditors catch
all four AI Agent defensive-hallucination classes (=G2= in [[file:../../10-19-design/10-architecture/10.153-defensive-engineering-taxonomy-and-modular-organization.org][10.153]]) without
generating false positives on clean deterministic-boundary code.

- *Independent Gold*: Every case (=AG01=–=AG32=) has a fixed independent
  expected outcome (=pass= vs. =fail= + exact hallucination/anti-evasion class). Candidate
  auditor output never generates gold.
- *Native AST, Diff-Delta & Remediation Auditors Evaluated*:
  1. Zero-dependency TypeScript lexer & structural AST auditor (with exact
     1-based line/column positions and =E1=/=E2= anti-evasion):
     [[file:../../../languages-engineering/ts/defense/agent-audit/ts-ast-auditor.ts][ts-ast-auditor.ts]]
     (executed via
     [[file:../../../languages-engineering/ts/defense/agent-audit/agent-benchmark.test.ts][agent-benchmark.test.ts]]).
  2. Pure Scheme S-expression AST auditor: =audit-scheme-defensive-datums= in
     [[file:../../../library/defensive-governance/func.ss][defensive-governance/func.ss]]
     (executed via
     [[file:../../../t/yanxu/Library/defensive-governance/agent-benchmark-test.ss][agent-benchmark-test.ss]]).
  3. Multi-language (TS/C/C++/Rust/Scheme) unified diff, =E3= obligation-deletion,
     SARIF 2.1.0, and =C2= remediation CLI auditor:
     [[file:../../../languages-engineering/ts/defense/agent-audit/multi-lang-auditor.ts][multi-lang-auditor.ts]],
     [[file:../../../languages-engineering/ts/defense/agent-audit/remediation-catalog.ts][remediation-catalog.ts]],
     and

     (executed via
     [[file:../../../languages-engineering/ts/defense/agent-audit/agent-defense-audit.test.ts][agent-defense-audit.test.ts]]

* Limits
:PROPERTIES:
:CUSTOM_ID: bench3005-limits
:END:

This 32-case benchmark establishes deterministic AST-level and diff-delta
precision and recall on its declared TypeScript, Scheme, C, C++, and Rust
cohort. It does not claim interprocedural dataflow completeness, whole-program
alias analysis, or coverage of arbitrary obfuscated evasion patterns across
external repositories.
