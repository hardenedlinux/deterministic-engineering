* Benchmark Scope and Independent Gold Policy
:PROPERTIES:
:CUSTOM_ID: bench3005-scope
:STATUS: implemented-verified
:END:

This benchmark evaluates whether AST-level defensive-engineering auditors catch
all four AI Agent defensive-hallucination classes (=G2= in [[file:../../10-19-design/10-architecture/10.153-defensive-engineering-taxonomy-and-modular-organization.org][10.153]]) without
generating false positives on clean deterministic-boundary code.

- *Independent Gold*: Every case (=AG01=–=AG45=) has a fixed independent
  expected outcome (=pass= vs. =fail= + exact hallucination/anti-evasion/escalation/durable-resume class). Candidate
  auditor output never generates gold.

* Limits
:PROPERTIES:
:CUSTOM_ID: bench3005-limits
:END:

This 45-case benchmark establishes deterministic AST-level, diff-delta,
scope-fencing, bounded closed-loop, hot-policy co-evolution, async-cut, and
crash-resumable Merkle governance precision and recall on its declared
TypeScript, Scheme, C, C++, and Rust cohort. It does not claim interprocedural
dataflow completeness, whole-program alias analysis, or coverage of arbitrary
obfuscated evasion patterns across external repositories.
