* Scope and current conclusion
:PROPERTIES:
:CUSTOM_ID: i0-scope
:END:

I0 prepares one explicit, compatible source/API/build/load cohort for the complete
declarative slice. Current declarations, package checkouts, private formation mounts
and compiled directories describe different cohorts. None is qualified as the target
baseline. The target direction is the current ownership split and Yuanxu public
surface, with directly migrated consumers, not a compatibility alias preserving the
old :core or ASCENT application APIs.

This update inspects files, Git metadata, symlinks and artifact bytes only. It does
not install/update/clean packages, modify source or models, invoke Gerbil, compile,
load a Module, run inference/acceptance/recovery, publish or expand orchestration.
Document lint/export, file-link checks and D2 rendering are the only executed checks.
All acceptance controls below are future requirements, not new receipts.

I0 ends with an agreed, source-bound selection and repair plan. Actual complete
build/load/cold qualification and normalized K1/SD/S1 behavior are I1 gates. Designing
or recording a cohort must not claim that those gates already pass.
