* Problem: External Non-Reversible Effects & Economic Denial-of-Wallet in Agent Swarms
:PROPERTIES:
:CUSTOM_ID: saga163-problem
:STATUS: implemented-verified
:END:

Pure Merkle rollback (=B1=) suffices for internal repository/artifact state,
but autonomous multi-agent workflows routinely invoke *external, heterogeneous
side effects* (cloud IAM/GPU provisioning, payment pre-auths, wire transfers,
external webhooks, paid LLM/API calls). Two failure modes dominate production:

1. *Uncompensated Partial External Side Effects & Illegal Post-Pivot Rollback*:
   When Step 3 fails after Steps 1–2 mutated external APIs, naive retry loops
   either leak cloud/financial resources (missing write-ahead compensators),
   blindly retry/cancel an unresolved =PendingUnknownEffect= timeout, or attempt
   impossible backward rollback after crossing an irreversible *Pivot*
   (Garcia-Molina & Salem, SIGMOD 1987; Helland, CIDR 2007).
2. *Autonomous Budget Runaway (Economic Denial-of-Wallet)*:
   A looping or delegated multi-agent subtree can burn unbounded LLM tokens or
   external API spend unless resource budgets obey a *linear conservation law*
   across delegation hops (inspired by KeyKOS/seL4 capability accounting).

* Architecture (Scenario B6): Write-Ahead Sagas × Linear M3 Budget Trees
:PROPERTIES:
:CUSTOM_ID: saga163-architecture
:STATUS: implemented-verified
:END:

| Governance Mechanism | Stratification & Invariant | Guarantee |
|----------------------+----------------------------+-----------|
| Effect Reversibility Typing | Every Saga step declares =ReadOnlyIdempotent=, =Compensable= (requires write-ahead =M1= compensator spec + callback), or =PivotIrreversible= (at most one pivot; zero compensable steps after pivot) | Prevents unregistered side effects and multi-pivot deadlocks at registration time |
| Deterministic Reverse Compensation & Pivot Fence | Pre-pivot failure triggers reverse-order idempotent compensation; post-pivot failure returns =RollForwardRequired= and refutes =attemptBackwardRollback= (=rollback-forbidden-past-pivot=); timeout fences to =PendingUnknownEffect= until reconciled | Zero leaked cloud resources, zero duplicate timeouts, zero illegal post-pivot undo |
| Linear =M3= Resource Budget Tree (=LinearBudgetTree=) | Branded with =M3_NON_SERIALIZABLE_CAPABILITY= (=R3=); =splitSubBudget= atomically transfers units parent -> child so =\Sigma remaining + \Sigma spent === rootBudget=; exhaustion triggers =BudgetExhaustedHalt= while keeping committed =M1= work pinned | Eliminates budget amplification across sub-agents and runaway cost loops |

* Limits
:PROPERTIES:
:CUSTOM_ID: saga163-limits
:STATUS: implemented-verified
:END:

External vendor idempotency depends on the target API honoring the deterministic
=idempotencyKey= / =compensationIdempotencyKey= emitted by the Saga engine.
Production deployments should pair =PendingUnknownEffect= reconciliation with
vendor query APIs or webhook status poller loops, and meter LLM token costs via
provider billing receipts before crediting unused reserved budget back to parent.
