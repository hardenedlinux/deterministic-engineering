* DESIGN Objective and authority boundary
:PROPERTIES:
:CUSTOM_ID: s5-ascent-projection-query
:STATUS: Existing-file/relation/call design only; no implementation, Session execution or Q issuance
:END:

S5 projects recognized C, independently required duties, actual A/E/G/W and fresh
qualified uses into the existing ResourceEvidence ASCENT program. A completed,
owned Q identifies the actual accepted program/source/result/request cut for
Aitia. Determinate means complete finite consequences at that cut, including
pending, counter, conflict and unsupported findings; it does not mean all green,
approved, adopted or delivered. No technical view grants project authority.

Library owns catalog/claim/coverage meaning; Scenario owns project C association;
method/content producers own actual W/use recognition; ResourceEvidence owns
trusted projection and query publication. ASCENT Session remains sole application
fact/transaction owner. Aitia independently verifies exact C/Q and policy/products/
roles/history under later stages. No second fact database, generic schema engine,
executor, evidence signer or review/disposition engine is introduced.

* SPECIFIED Source relations and exact identity domains
:PROPERTIES:
:CUSTOM_ID: s5-source-relations
:END:

C = acquired occurrence; D = required duty instance; K = required coverage unit;
A = concrete application; E = actual attempt; W = original private result;
U = fresh target use; B = exact semantic/input basis; G = actual run/derivation
group. K exists before any A/W. One Rust A/E can issue six W, while SI/TM have
their own attempts and bind the exact original upstream Rust G. These identities
are not interchangeable with a case name, digest, version or observation filename.

| Source relation / fields retained from 10.47 | Trusted invariant |
|--------------------------------------------+-------------------|
| capture(C, selection, project, revision, scope, purpose) | Actual recognized C and checked model/parents/policy/Profile association |
| required_duty(C, D, subject, claim, coverage_policy) | Independently derived mandatory Library/project demand; no result needed |
| required_unit(C, D, K, subject, claim, capability, domain, strength) | Finite required facet/criterion/method/case and supported coverage meaning |
| required_role(C, K, role) | Independent complete material input demand, including semantic/execution/validation/upstream roles |
| application(C, A, capability, domain, application_basis) | Actual prepared application, never a caller label |
| application_claim(C, A, K, subject, claim, B) | One supported target claim/unit/basis; no mutable latest run slot |
| expected_input(C, A, K, role, binding) | Unique qualified expected captured/derived input at that claim |
| attempt(C, A, E, G, execution, interpretation, diagnostic) | Actual attempt, no invented execution before A; missing application stays gap |
| witness(W, C0, A0, E0, subject, claim, basis, G, strength, conclusion, issuer) | Actual recognized original W and immutable origin, holds/refuted scoped meaning |
| witness_input(W, role, binding) | Complete real observation footprint; imported report arrays do not choose it |
| qualified_use(U, C, A, K, W, B, G, verification) | Actual fresh verifier/producer operation for exact target and sufficient meaning |
| use_status(C, A, K, W, verification, state, finding) | Exact verification identity/status/cut; old failed check cannot name-join a newer U |
| upstream_use(C, A, K, role, U, W, G) | Qualified required original facet/run/derivation, not equal-byte common origin |
| comparison_group(C, K, U, group) | Trusted comparable proposition/subject/domain/strength/basis, not arbitrary run equality |
| control_observation(U, expectation, result, finding) | Independent actual control dimension; never changes semantic polarity |
| projection_gap(C, target_kind, target, category, subject, finding) | Exact missing/unsupported/inaccessible/stale/invalid operation/role/product diagnostic |
| historical_reference(C, reference, subject, revision, scope, category, origin) | Original evidence/history/custody limits, no implicit current eligibility |
| trace_link(C, from_kind, from_id, relation, to_kind, to_id, basis) | Typed checked-strength product/model/decision/duty/application/evidence association |

Cells are declared finite enum symbols, bounded exact integers or owned nonempty
reference strings. Reject floats/NaN, arbitrary objects, hash tables, callbacks,
unknown enum values and unbounded IDs; never intern arbitrary supplied IDs. Copy
string cells/spines on ingress and public presentation. Large artifacts/ordered
traces stay exact immutable owner references or explicit bounded ordinal rows.
Set admission may deduplicate exact repeated rows but never distinct E/W/U origins.

Functional keys: C selection; C/D/K definition; C/A identity; C/A/K claim/basis;
C/A/E group; C/A/K/role binding; W original identity/origin; W/role binding; U
complete target/verification. Incompatible duplicate identity refuses the candidate
transaction, not latest-row-wins. Compare complete target and original bases via
actually qualified compatibility maps if supported; such a map is itself an input.
Fresh cross-C reuse can be valid, but neither C0=C equality nor digest equality
alone establishes the use. Missing/extra/conflicting/empty material role inventories
cannot become applicable through vacuous negation.

Old sources migrate directly: usage/snapshot/entry application -> capture plus
independent D/K; catalog/factor/dependency -> checked finite required expansion;
global scope -> exact A/K expected_input; checked -> actual qualified_use/status;
old witness -> original W or explicit historical reference. Historical output
files retain old semantics; no permanent legacy alias or raw checked-row route.

* SPECIFIED Candidate transaction, rollback and publication states
:PROPERTIES:
:CUSTOM_ID: s5-transaction-boundaries
:END:

1. Actual serialized Evidence owner resolves checked program/C/catalog/provider/
   predicate/codec/source/load association and query scope. Independently expands
   complete required relations before outcomes; refuses malformed mandatory catalog.
2. Actual producers/verifiers supply recognized W and fresh uses/status; retain A/E/G,
   failed attempts, missing applications/products/reviewers and original history.
   Validate/copy primitive facts and functional keys, exclude invalid uses with
   diagnostics. Honest pending/counter/conflict does not make Q nonconforming.
3. Build a complete dependent batch: required inventory, applications/inputs/attempts,
   original witnesses/history, current uses/status, traces and gaps, including named
   empty relations. Replace current eligibility as a whole; omission cannot preserve
   withdrawn/stale U. Read history from actual accepted owners, not a shadow union.
4. Call existing gerbil-ascent-session-replace-sources! under actually qualified
   execution control. Trusted accept-result receives prospective finished result;
   check actual source rows versus complete prepared set, expected program/outputs,
   exact eligibility/currentness association, and bounded materialization. Return
   exact #t only for conformance; no reentry, caller predicates or external publication.
5. After successful Session return, bind projection metadata to the actual accepted
   returned result and owner, then freeze/publish complete Q for checked request.
   Candidate rows prepared in callback remain private until actual final acceptance.

| Transition / failure | State and permitted external observation |
|-----------------------+------------------------------------------|
| Preflight malformed fields/keys/required inventory | No source change; retain diagnostic and previous accepted association |
| Later source validation, duplicate replacement name, provider/predicate/budget/evaluation failure | Prospective batch refuses with prior accepted sources/result retained; no partial accepted Q |
| Callback false, truthy non-#t, exception or Session reentry | No commit; no prospective Q leak. Reentry protection is not independent-writer serialization |
| Partial/timeout/interrupted unknown completion | Preserve actual partial/diagnostic at its scope; last finished old result is not this cut's complete answer |
| Final Session acceptance succeeds; later view/export/write fails | Session remains committed. Retain exact accepted association; recover/freeze that same result or report unavailable publication, never invent rollback or duplicate commit |
| Failed update after external source/role/receipt drift | Old Q remains immutable history; rollback cannot restore external validity or automatic current use |
| Counter/history/withdrawal changes declared query input | Replace accepted source cut and issue new Q with obligations/history/negatives intact; no edit to prior Q |

The trusted owner binds actual returned result/source association; do not invent
public engine commit-ID accessors or serialize private source-snapshot objects as
authority. Accept-result compares set/field semantics and names all required source/
output relations, including empty ones. No query inside callback invokes Session
again. Only actual supported execution-control bounds the real batch; a timed
read of a later cached result cannot bound earlier evaluation. Row preparation,
callback copies and canonical export also need finite qualified bounds. Current
4096 labels alone do not justify expanded cardinalities or whole-operation limits.

Clue exchange/trajectory issuance, producer observations and files can precede the
project batch; they retain their actual history after a failed transaction. No
multi-owner rollback or deletion of counters is claimed. Host loss may leave
completion/publication unknown; retained in-process snapshots are not automatic
crash-durable file transactions. Recovery must genuinely re-admit source/program/
use and record any new evaluation as new, never reconstruct private acceptance
from a surviving JSON. Source/status checks expose their actual cut and limits,
not an atomic global filesystem/authority transaction.

* SPECIFIED Complete Q and deterministic presentation
:PROPERTIES:
:CUSTOM_ID: s5-query-fields-and-determinism
:END:

inventory, supported filters/set-order interpretation, domain/coverage and finite

requires full policy-required view; counts/support-only selection cannot claim it.

|------------------------------------------+-------------------------|
| identity / owner / provenance | Accepted projection and returned finished result, actual publication owner/source and qualified reproducible content reference; public hash/identity alone is not issuance |
| capture / selection / project | Exact C, checked model/parent/Contract owner and semantic revisions, Profile/policy/project revision/subject/scope/purpose; no copied generation authority |
| program | Actual admitted rules/fields/queries, relevant predicates/codec/catalog/provider/engine/runtime/source/compiled/loaded association and supported limits; not separately supplied rules-path or package label |
| source-basis | Complete normalized accepted relation names and owned values/refs, explicit empties, exact A/E/G/W/U/history/status/gap/trace and observed currentness limitations |
| request | Exact query/output inventory, filters, scope, finite domain/limits and coverage/set/ordering semantics |
| completion / limitations | Actual finished evaluation plus complete required extraction/encoding; honest missing/unsupported/unknown, source/trust/currentness limits and authority exclusions |
| rows / explanation | All required named result sets and exact C/D/K/A/E/W/U/B/G/input/finding references; no live callback or mutable Session view pretending to be frozen |
| applicability / use | Original immutable cut plus actual later owner-qualified current-use checks when requested, not self-asserted current? or Aitia receipt |

Admitted missing/inaccessible product facts may yield a complete honest Q. Missing
required Q rows/provenance or incomplete extraction cannot be replaced with empty
arrays and called complete. Engine finished alone is insufficient. Q owns public
strings/spines; getters must not expose mutable aliases into accepted rows or
private metadata. Artifact serialization is not portable private authority.

Pure typed canonical encoding belongs to Evidence owner: scalar type tags and
field boundaries, exact finite types/sizes, named empty sets, stable declared set
ordering and exact-repeat dedup. Symbol/string must remain distinct; no floats/NaN,
arbitrary printing/interning/hash iteration/timestamp-derived logical identity.
Distinct E/W/U remain distinct; ordered traces preserve ordinals or exact artifact
refs. Codec and normalization basis are themselves admitted program/Q inputs.
Fixed accepted primitive sources/program/request/codec yield the same consequences
and logical content reference under qualified controls. This does not imply
external execution, scheduling, acquisition or human reasoning is deterministic.
Actual publication/attempt identities and timing may differ while logical content
is equal. New evidence/uses/status/catalog/query/program creates the appropriate
new projection/Q; equivalent rereads do not invent new execution or new truth.
