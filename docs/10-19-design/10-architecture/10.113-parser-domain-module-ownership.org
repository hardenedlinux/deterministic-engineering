* Scope and baseline
This implementation slice removes the misleading =src/modules= container from
Parser PR13. It does not enable std Djot, alter Gerbil/SDK, change dependency
revisions, add a builder, or broaden test/resource controls. The prior qualified
Parser baseline is461fa6f; this slice must earn new current-head Linux/macOS CI.
Root Library implementation changes are outside this Parser commit.

| Previous owner | Current owner | Boundary |
|----------------+---------------+----------|

The former directory is removed, without compatibility forwarding modules. Source
module identities change and consumers must rebuild. External object kinds,
Grammar schemas, algorithms and caller data protocols retain their meanings.
The pure Grammar projection stops re-exporting source-pattern helpers; the
explicit author facade composes those helpers from their language owner.

* Declarative composition and build ownership
=init.ss= selects =build-support=, =compiler=, =ffi=, =grammar=, =graph=,
=language=, =runtime=, =testing= and =utilities= directly through Yuanxu
=:load-modules "./src"=. No second directory walker, resolver or build registry
is introduced. Core retains source admission, normalized Scope and
=std-make-spec= projection. Standard Gerbil build/test entries retain execution.

Graph's Build contribution owns graph-query/support and graph-syntax/support.
Language's contribution owns language products and the package's declaration/API
facades. Testing's contribution owns its loader adapter. The independent native
package-discovery reference excludes the new graph Build role just as it excludes
other phase-bound Build roles. =dev/build.ss check-catalog= compares the complete
native specifications including FFI options and rejects legacy published targets.

Formal evidence discovery now includes grammar/graph domain sources and the
explicit declaration facade. A source move must not silently remove those inputs
from future model observation footprints. This is input coverage, not a new proof.
