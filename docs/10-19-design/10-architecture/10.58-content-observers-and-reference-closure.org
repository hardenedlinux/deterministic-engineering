:PROPERTIES:
:CUSTOM_ID: s4b-content-observers

Org, decision and trace observations under the selected checked design policy.

review receipt, decision authorization, adopted architecture or delivery.

* SPECIFIED Same-C calls and finite reference closure
:PROPERTIES:
:CUSTOM_ID: s4b-calls-and-closure
:END:

| Target operation / owner | Input -> output / boundary |
|--------------------------+----------------------------|
| Prepare / Scenario + checked content capability | Recognized C + selected bounded subject/criterion/request + actual qualified upstream bindings -> returned checked A or exact missing-input gap/refusal; no replacement root/Profile/manifest/reader/policy/tool |
| Parse/index / actual qualified reader | C's owned bytes and captured reader/format/selector policy -> owned candidates/spans/index/diagnostics. Never hash a path then reopen ambient content |
| Resolve/check / closure observer | A + indices + independent demand/typed references + acquired target inventory -> scoped resolved graph and per-edge findings, not semantic approval or another source acquisition |
| Inspect / actual model/source/view/decision observer | Exact resolved inputs and supported rules -> E/G and scoped observations; render/generated artifacts carry actual derivation/command origins |
| Attribute / qualified semantic operation | Same C/criterion/product/source basis plus actual finding -> scoped attribution/meaning observation or unresolved gap. No fabricated human reasoning execution, role appointment or signature-implies-truth rule |
| Issue/use / common trusted producer | Accepted bounded holds/refuted observation with actual E/closure -> private W; original W plus target C/A -> fresh use. Missing/access/parse failure retains diagnostics and no invented property W |
| Project / WP06, then adapt / WP07 | Independent required units plus actual C/A/E/G/W/uses/findings -> Q -> exact C/Q-bound R and independent verification; no raw checked-row publication or observer-as-disposition shortcut |

Acquisition belongs to S3. A bounded reader may help discover required candidate
inputs before capture; Scenario then owns actual acquired bytes or declared gaps.
After capture the observer resolves only already-owned inputs or a genuinely
qualified immutable domain included in C. A new ambient required target needs
new acquisition/C; it cannot be fetched and silently appended during validation.

The closure algorithm is a finite typed demand graph, not every hyperlink:

1. Root expected roles/claims and required relation kinds in the selected checked
   policy/capability and actual trusted project requirements. Candidate omission
   cannot remove a role or reclassify required dependency as context-only.
2. Resolve supported selectors from owning artifact/base/origin, not cwd or output
   directory. Preserve actual path/case/alias/symlink/custody associations; same
   basename/title/content alone is not subject/source identity. Duplicate IDs or
   incompatible authoritative bindings refuse the ambiguous claim with originals.
3. Keep each incoming demand edge and referring span even when targets are shared.
   Use visited state keyed to qualified artifact/subject/revision/selector basis;
   preserve edge provenance. Cross-reference cycles are allowed under finite
   traversal; decision supersession must be acyclic. Neither drops required edges.
4. Supported ID/heading/file/include/macro/remote forms have explicit reader/recipe/
   access prerequisites. Parse Org as inert data; never execute Babel/eval/export
   filters, shell blocks, includes or prose instructions. Context-only remote URL
   is recorded without fetching it as proof; inaccessible required target is a gap.
5. A historical report may delegate only expected bounded leaf roles for its exact
   schema/subject. Report arrays cannot choose overall policy demand. Resolve exact
   artifact roles; conflicting digests or ambiguous suffix matches refuse, never
   first/last-file-wins. Preserve source-copy and original custody identities.
6. Enforce finite node/edge/depth/byte/time budgets with actual owner guarantees and
   record counts/limit/completion. Exhaustion or incomplete search is undetermined,
   not closed or false. Immutable captured graph does not imply atomic whole-FS
   snapshot or discover every external dependency.
7. Bind full acquired file identities, exact selected spans, actual parser/recipe/
   source/load/tool and relation meaning. Whole-file changes invalidate under the
   current coarse policy; section-only reuse requires a qualified finer footprint.

Ambiguous bindings (duplicate selector, incompatible authoritative bytes or
mandatory source origin) refuse the affected application while retaining offending
candidates. Two qualified opposed observations retain both W and use associations;
latest-looking revision, majority green or successful parser is no adjudicator.
A complete qualified search may refute a precise unique-selector/completeness claim;
inaccessible input/parser failure/incomplete search cannot refute unrelated
architecture truth. Keep all five S4a dimensions: execution, validation, semantic,
control and applicability. Deliberately removed anchor may meet the control while
refuting its exact content claim.

10.34/90.97 were historical outputs excluded from their own input catalog. A new
C may capture that finalized old draft. New observer W/reports, Q and final dossier
are later outputs; a final manifest references actual identified Q/W/products
before R binds it. Forward placeholder is a gap, not issued evidence or a hash
self-cycle. Keep the original 138-entry catalog and its recorded digests unchanged.

Captured history cut is bounded; it does not prove no later counter or withdrawal
exists. Current role/history/receipt status may block use/review without rewriting
C/W. Changed captured mandate/product/requirement meaning requires new C; status
or query changes refresh affected use/Q/R through WP06-WP08 at their actual owner.
