* Core Thesis: Durable Merkle Evidence as Truth, LLM Context as Ephemeral Materialized View
:PROPERTIES:
:CUSTOM_ID: dai157-thesis
:STATUS: implemented-verified
:END:

Long-horizon multi-agent AI systems suffer from two compounding pathologies when
conversation history (=Context=) is conflated with authoritative persistent
state (=Durable State=):

1. *Overthinking & Circular Re-Derivation*: After context compaction or agent
   handoff, the LLM cannot distinguish already-settled truths from disproved
   dead-ends and open obligations. It burns thinking tokens re-deriving proven
   invariants, re-exploring previously refuted designs, or hallucinating
   contradictions.
2. *Context Pollution & Semantic Write-Skew*: Passing raw prose across agent
   boundaries lets prompt-injection or overconfident Coder summaries bias the
   Reviewer; meanwhile, concurrent agents editing disjoint files still break
   interfaces via unnoticed *ReadSet × WriteSet* (=rw=-antidependency) write-skew.

Drawing on =gerbil-persist= (content-addressed immutable =M1= graphs + minimal
atomic =M3= root) and Cahill, Röhm & Fekete's *Serializable Snapshot Isolation
(SSI)* (SIGMOD 2008 / ACM TODS 2009), we enforce a strict *Truth vs. View vs.
Live-Capability* split:

| Plane | Role | Persistence & Lifecycle | Anti-Overthinking / Governance Effect |
|-------+------+-------------------------+---------------------------------------|
| *Durable Evidence Graph (Truth)* | =ContentAddressedKvStore= (=M1= Merkle DAG + =M3= root) | Permanent, content-addressed, compaction-immune | Preserves settled =Proven= proofs, =Refuted= dead-end witnesses, and =M2= policy manifests with zero amnesia |
| *Role-Projected Context (View)* | =projectRoleContext= in [[file:../../../languages-engineering/ts/defense/agent-audit/durable-ai-context.ts][durable-ai-context.ts]] | Ephemeral materialized view reconstructed deterministically from the Merkle root | Projects settled =M1= facts as O(1) hash anchors (=rethinkForbidden: true=), pins =Refuted= dead-ends, isolates the narrow =Pending= frontier, and strips Coder prose from Reviewer views |
| *Multi-Agent SSI & Lease Fence* | =evaluateMultiAgentSsiMerge= + [[file:../../../packages/quint-models/engineering/defense/durable-ai-context-ssi/DurableAiContextSsi.qnt][DurableAiContextSsi.qnt]] | Per-branch =ReadSet × WriteSet= digests + monotonic =M3= fencing epoch | Catches disjoint-file semantic write-skew (=PendingRevalidation=) and blocks stalled zombie workers (=fenced-stale-agent-epoch=) |

* Limits
:PROPERTIES:
:CUSTOM_ID: dai157-limits
:END:

The =ReadSet × WriteSet= SSI check operates at declared file/contract digest
granularity; finer symbol-level AST dependency extraction is a clean orthogonal
refinement on top of the same =evaluateMultiAgentSsiMerge= contract. Reviewer
context sanitization removes free-form prose channels but does not eliminate
covert steganography embedded inside syntactically valid code diffs.
