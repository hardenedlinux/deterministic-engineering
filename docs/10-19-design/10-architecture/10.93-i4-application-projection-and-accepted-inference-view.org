* Scope, ownership and current verdict
:PROPERTIES:
:CUSTOM_ID: i4-scope
:END:

I4 consumes one genuine original C and its actual selected Program/operation binding,
projects complete application inputs, runs the existing synchronous ASCENT Session,
and returns an owner-associated immutable accepted inference view for SysML selection.
Accepted means this actual bounded computation and application projection were
accepted under their declared contracts. It does not mean a candidate is correct,
all evidence is positive, a model is validated or publication is authorized.

#+begin_example
I0 actual source/load + I1 checked Scope + I2 real Program binding + I3 genuine C
 -> checked request/current-use cut -> independent demand + complete owned projection
 -> native prospective replacement -> pure accept-result -> native final checkpoint
 -> successful actual returned result -> frozen admitted inference view
 -> same-C SysML request selects candidate/plan/catalog/mapping under I5
#+end_example

This is source inspection and Org/D2 design only. No implementation/model change,
C acquisition, Program execution, acceptance/build/load/recovery, model validation,
publication or orchestration expansion is performed. Document checks/rendering do
not qualify runtime behavior. I0--I3 remain actual execution prerequisites.

ASCENT owns generic rule evaluation, source transactions and immutable result
snapshots; the application Module owns C-to-fact semantics, complete demand/coverage,
trusted input recognition and accepted-view association. Library owns declared
meaning, Scenario owns real acquisition and current-origin operations, and actual
method/evidence/Host owners recognize A/E/W/use. No duplicate evaluator, mutable fact
mirror, scheduler, issuer registry or public raw-fact upload API is introduced.

Expected source/output inventories come from the actual bound Program and its
published application Type/operation contract. A second hand-maintained label list
cannot define what was executed. Labels cannot hide unlabelled source handles or
opaque guards/providers. All controlled sources are accounted for; any other source
must be independently declared/fixed and included in the captured Program basis,
not left as ambient mutable engine state.

One capture and one actual Program binding scope a private Session. Use a fresh
Session for this synchronous route. If later retaining a Session for current-use
refresh, require actual qualified single-writer ownership and complete replacement,
including empty status/use relations. Native reentry rejection is not concurrency
serialization. A new C or changed rules/schema/codec/predicate/provider meaning needs
a new qualified binding/Session and, when captured meaning changes, a new C.

The local codec binds primitive refs to actual admitted immutable meanings and
opaque qualified operation associations. It is neither a global registry nor
origin authentication. Deep-own strings/containers; reject unknown/foreign refs.
Preserve actual ordered/occurrence versus set semantics and budget charging for
duplicates; do not silently deduplicate bags or use counts as coverage. Projection
performs no IO, evidence issuance, tool execution, external verification or recapture.

Demand is derived independently from selected definitions/policies/parameters and
supported candidate/plan applicability before outcomes. All required units survive
even if no candidate offers them, no evidence exists or no model node is emitted.
Complete accounting may correctly show missing inputs; it does not establish every
input is available or every obligation is satisfied. Closed-world negation applies
only to the completely accounted finite domain, never to unknown repo-wide facts.

expected_use_check makes the exact required-check join explicit. Every required
check must have an adequate positive finding at its chosen cut, with no applicable
contrary/unestablished finding; missing status blocks use. Empty check requirements
cannot silently mean eligible. Any exception must be an independently recognized
no-demand basis supported by the full use Contract. Do not select a cut using the
largest timestamp or a caller's newest-looking label.

For sources carrying A/E/W/use/check refs, actual full 10.70/10.77 and producer
contracts remain authoritative. They retain input footprints, causal/model premises,
check/impact, result polarity, strength and actual execution provenance. A short row
is a projection into the finite engine, not a replacement contract. Unsupported
full association refuses trusted projection; authentic unavailable/negative findings
remain gaps/counterevidence. Unknown status or unsupported semantic pair refuses.

Reference roles remain explicit: capture.basis-ref names C's owned basis;
expected/observed input bases name their actual unit material; qualified_use.basis-ref
names the target-use basis bound to this C. witness-ref retains the witness's original
execution/basis and any recognized reuse/non-impact justification; it is not relabelled
as a new execution on C. origin-ref is a typed owner association for that acquisition,
finding or use, not an interchangeable universal origin credential. Status cuts are
actual owner-selected observations, not trusted merely because their times look recent.

Coverage envelope is checked outside Datalog against genuine C/owner associations.
It is not a self-certifying coverage=true fact supplied by an LLM. The trusted
projection checks each required unit/input/check and its applicability, not merely
that every source name exists. Sources empty because no evidence is available must
still leave independent evidence requirements/gaps visible.

A recognized positive use and a recognized refuting use may both remain observable;
the unit is conflicted and cannot acquire an unqualified successful conclusion.
A stale or unestablished use remains visible but cannot enter qualified_support.
Projection must use the full claim polarity: M06 harness success is not positive
ownership, Lean counter to a positive bound stays counter, and QNT path reachability
keeps its actual asserted property. No empirical causal estimator or proof checker
is implemented as a Datalog guard.

Observation that a declaration says established is evidence only of that observed
assertion, not its proposition. C origin concerns the actual acquisition; method
witnesses concern their bounded claims. Structural coverage is not implemented
architecture; SysML syntax is not property truth; QNT exploration is not universal
Rust refinement; a current-use check is not Aitia authorization.

I4 accepts complete negative/gap-bearing views. Structural model projection can be
allowed for a preselected bounded design activity despite explicit method-evidence
gaps only if its actual policy permits it and all mandatory model-input conditions
hold. It does not waive the broader case's duties or automatically authorize I5
materialization/validation/publication. Missing source/model context is not green.

The old eight conflicts/34 gaps/nine nodes/eleven edges and four LIB-C01 capability
gaps remain historical structural observations. Compare their semantic subset under
matching declarations when migrating tests; do not require unchanged total counts
once new coverage/evidence outputs exist. An all-established synthetic case may
produce declared_ready while genuine qualified support remains absent.

Application acceptance is supplied by the actual expected Module operation and its
retained successful C/Program/batch/result association. POO Type conformance,
accepted=true, a hash, arbitrary rows-of object or internal engine publication token
cannot authenticate an application view. Same-process Scenario/Module calls must
preserve the actual operation handoff/owner recognition. If the selected interface
cannot recognize that association, the SysML trusted handoff is blocked; do not add
a global view/epoch registry, duplicate result issuer or portable credential claim.
Reloaded reports can be historical input, not silently reissued accepted views.

Freeze from the private successful result/validated prospective extraction, not lazy
live Session getters. Native public readers detach row pairs, not arbitrary mutable
nested payloads; enforce actual primitive codec ownership. Canonicalization of an
inspection report must not erase row semantics or shared evidence meaning.
Recorded-rule-explanation/trace links are limited provenance and diagnostics; they
are not per-row logical proofs, causal identification or execution permission.

The selected execution-control and whole-operation budgets cover preparation,
field predicates, evaluation, callback extraction/freezing and canonical export.
A completed cached run-timeout call cannot retroactively bound earlier work. Actual
source/provider/predicate stability/purity must be qualified; finished is insufficient.
No row truncation, silently increased 4096 budget or expanded heap/watchdog obtains
acceptance. Actor/async routes require separate qualification and are not substitutes.

* Failure, invalidation and refresh states
:PROPERTIES:
:CUSTOM_ID: i4-invalidation
:END:

| Event | Retained state and required response |
|-------+--------------------------------------|
| Malformed encoding/foreign C/forged evidence/incomplete mandatory coverage | Reject before native mutation, retain actual diagnostic and prior accepted association. Forged data cannot become a genuine negative witness |
| Row predicate/budget/evaluation/callback/final native checkpoint failure | No new application view; retained Session keeps prior accepted sources/result under its native contract. A fresh failed invocation yields no accepted view |
| Freeze/value admission failure after native adoption | Native state may already have committed; expose no new half-view and retain actual result plus application failure. Do not claim rollback of a successful native adoption |
| External origin/use/premise revocation during computation | Refuse affected current use at actual owner and retain counter/findings. Session rollback does not undo external revocation or issue a new origin |
| Captured intent/definition/parameter/plan/policy/Program/source meaning changes | Genuine new selection/acquisition/C/binding as required; old view remains historical conditional output, never relabelled current |
| Unchanged C, newly recognized use/status/check/causal applicability findings | Complete fresh controlled cut, including explicit empty relations; no union of historical eligible rows. Reuse only under actual complete footprint and non-impact/currentness support |
| Missing/refuted/unknown causal premise or incomplete impact coverage | Keep exact affected unit/use/premise/check and uncertainty; block unsupported reliance. No global minimal cone or unaffected proof inferred from absent dependency edges |
| Later filesystem model/publication failure | Separate I5 candidate/validation and I6 publication states; native Session rollback and build restoration do not reverse external writes or restore original C provenance |

Freeze/admission and native adoption are not a distributed two-phase commit. There
is no need for a shadow fact store. Historical immutable rows remain inspectable
when current use fails, but their old eligibility cannot be revived by timestamp,
latest-looking revision, copied receipt or matching content digest.
