* Retained small adapters
The pinned POO package has no Character Type declaration; Utilities' char?
Type is an explicit domain boundary, not a second character implementation.
Graph predicate results retain Scheme truth-value semantics, so arbitrary true
results are intentional rather than replaced by a strict Bool result contract.
BuildSpecification leaves std/make option tails opaque instead of duplicating
Gerbil's option language. Parser does not infer stronger semantics from those
forwarded payloads.

Native link selection asks Gerbil for its actual selected object, then checks
Parser namespace ownership and physical generation. Core's private build-artifact
generation validation is not an equivalent public runtime linker service. The
existing small adapter is retained with its ownership/error controls; no new
resolver or product registry is introduced.
