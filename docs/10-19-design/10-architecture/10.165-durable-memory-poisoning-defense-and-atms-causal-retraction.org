* Problem: Orthogonal Persistence Amplifies Memory Poisoning & Hallucination Sedimentation
:PROPERTIES:
:CUSTOM_ID: tms165-problem
:STATUS: implemented-verified
:END:

Giving long-horizon AI Agents persistent memory solves amnesia and overthinking
([[file:10.156-orthogonal-persistence-durable-multi-agent-governance.org][10.156]],
[[file:10.157-durable-ai-context-projection-and-multi-agent-ssi-concurrency.org][10.157]]),
but naive persistence creates a lethal inverse hazard: a single prompt-injected
rule or hallucination promoted into shared memory becomes a *permanent sleeper
backdoor* across all future sessions, spawning derived plans and secondary
beliefs that survive naive point deletion.

* Architecture (Scenario B8): Two-Tier Memory × Doyle/ATMS Causal Retraction
:PROPERTIES:
:CUSTOM_ID: tms165-architecture
:STATUS: implemented-verified
:END:

Grounded in *Doyle (AIJ 1979 TMS)*, *de Kleer (AIJ 1986 ATMS)*, and *Malkhi &
Reiter (1998 Byzantine Quorums)*:

| Governance Mechanism | Stratification & Formal Law | Security Guarantee |
|----------------------+-----------------------------+--------------------|
| =M2= Provisional vs. =M1= Verified Memory | All new LLM observations start quarantined in =M2= (=ProvisionalM2=); promotion to =M1= (=VerifiedM1=) requires =sourceIntegrity != UntrustedExternal= AND either a cold deterministic oracle receipt OR =k=-of-=N= independent witnesses (=attester != proposer=) | Single hallucinating agents and untrusted external inputs can never poison authoritative memory |
| ATMS Multi-Justification DAG | Derived beliefs store disjunctive lists of conjunctive justification sets (=string[][]=); =retractPoisonedBelief= propagates fixed-point retraction to every downstream node losing ALL valid supports, while preserving nodes with a surviving clean alternative justification and all unrelated beliefs (=DE01=) | Exact causal cleanup without global memory wipe |
| Poison Immunization Tombstones & =B3= Principal Cascade | Retraction pins an immutable =M1= =RetractionForensicTombstone= blocking future re-ingestion of the exact claim digest; =retractByCompromisedPrincipal= links =B3= contractor revocation directly to causal memory cleanup | Zero cross-session re-poisoning; revoking a compromised agent automatically retracts its unverified beliefs |

* Limits
:PROPERTIES:
:CUSTOM_ID: tms165-limits
:STATUS: implemented-verified
:END:

Canonical claim-digest immunization prevents exact and whitespace-normalized
re-ingestion of retracted poisoned claims. Production deployments defending
against adversarial paraphrasing of retracted rules should combine exact =M1=
tombstone immunization with embedding/policy-classifier screening at the =M2=
provisional intake gate.
