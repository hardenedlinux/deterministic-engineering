* Findings Caught and Hardened During Verification

1. **Dot-Qualified =.admit= False Positive in Lean Pre-Commit Gate**:
   Running full-mirror hygiene verification across all 38 Lean files in =packages/lean-models= uncovered that =DeterministicEngineering/Core/Conservation.lean= defines a legitimate domain method =OwnerPool.admit= (=p.admit x=). The previous regex =(^|[^[:alnum:]_])(sorry|admit)= in [[file:../../../packages/lean-models/.githooks/pre-commit][packages/lean-models/.githooks/pre-commit]] matched =.admit= as if it were the standalone tactic =admit=. Both the hook and [[file:../../../scripts/verify-subtree-mirrors.sh][scripts/verify-subtree-mirrors.sh]] now exclude dot-qualified identifiers (=[^[:alnum:]_.]=) while continuing to block standalone =sorry= and =admit= tactics, covered by regression test =H1= in [[file:../../../languages-engineering/ts/defense/agent-audit/subtree-git-hooks.test.ts][subtree-git-hooks.test.ts]].
2. **Pre-Publish Mirror Invariant Checks in CI**:
   [[file:../../../.github/workflows/publish-packages.yml][.github/workflows/publish-packages.yml]] now enforces two additional split-commit gates before pushing to any read-only mirror:
   - =lean-models=: verifies =lean-toolchain= is present in the split commit alongside =lakefile.toml= and =.githooks/pre-commit=.
   - =quint-models=: refuses to publish if the split tree contains any per-model =types.ss= file (enforcing 10.205 at the publish boundary).
3. **Downstream =cedar-poo-spec= Submodule Consumption Pattern**:
   Downstream Lake consumers declare their own =[[require]] name = "LeanPoo"= dependency (local submodule, path, or pinned git rev) ahead of =[[require]] name = "DeterministicEngineering" path = "vendor/lean-models"=. Lake's top-level requirement resolution cleanly satisfies =LeanPoo= without modifying the read-only =lean-models= mirror, compiling all 95 Lake jobs and proving =unpinned_base_weight_refused= with zero =sorryAx=.
