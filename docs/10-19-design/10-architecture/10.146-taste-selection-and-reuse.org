* Trust and invalidation
An EvidenceProjection is a declared, source-bound display observation. Its state
is not a verifier receipt, C/Q/R, authenticated execution or authorization.
Supported never grants acceptance. Unknown IDs, absent excerpt, unselected refs,
changed input under an old selection, or attempted fidelity removal refuse.
Reselection is explicit. The selection trace carries rule identity, rationale,
Question/subject/source refs and the complete input binding. Post-export review
still checks actual hashes and observations; readability is not aesthetic proof.

* Compiler allocation lifetime, package release and downstream admission

PR #5 is rebased onto the Git-installable root package from main. Its change is
a compiler allocation boundary, not a second build system: D2 still owns parsing
and model observations; the existing SDK Worker still owns compilation. A short
native child process owns that worker so process termination can return retained
Bun worker allocations instead of accumulating them in the publishing host.
The host accepts a result only after native process close and zero exit, with
exactly one response. It disconnects IPC on send errors and waits for close before
rejecting. No process-exit call, signal-kill fallback, compiler pool or new public
factory/configuration is introduced. Worker teardown precedes sending the result.

The IPC channel must remain referenced until teardown and send acknowledgement.
An attempted once-only listener locally caused premature exit without a result;
that failure was retained and the listener remains active until explicit disconnect.
Native lifecycle controls exercise spawn/IPC failures, missing and duplicate results,
nonzero exit and a real successful D2 result. The existing 24 sequential compilations
retain the 256-MiB parent RSS guard. These controls qualify this runtime and workload;
they do not prove arbitrary host heaps or all process-cancellation policies.

The root =package.json= remains the sole Render version declaration. Release tags,
package archives and notices derive from it. After both platform jobs and REUSE
pass on the exact head, squash PR #5, delete its branch and tag the merged source.
A standard Bun package archive is an optional Release artifact, not Cedar's input.
Cedar selects the merged Git commit in its existing manifest and Bun lockfile.

Cedar must re-render its captured SDK/D2 sources using the new installed package,
then pass the existing full tests and dependency/worker/artifact recovery controls.
Its job-local initial Bun cache is empty. Recovery removes only node_modules,
reinstalls from the same frozen lock and starts a new process to execute the real
D2 worker and verify existing exports. Missing HTML, changed captured sources or
mixed artifacts must reject; re-rendering cannot stand in for recovery acceptance.
Neither vendor, manual receipts, an additional publisher nor a Release URL is used.
The upstream and downstream CI results qualify their respective revisions separately;
a release tag alone grants neither model publication nor Aitia review authority.


* Image compression and measured format choice

Sharp (pinned in root package.json) owns native PNG/WebP encoding after the existing
browser screenshot. Both default paths are lossless. The export returns compatible
PNG, optional WebP and a preferredRaster selected by actual encoded byte count;
format and MIME accompany the selected bytes. Native encoder settings and final
hashes are retained in the existing receipt. Models, D2/SysML identity, Questions,
fonts, dimensions and SVG composition do not select a hardcoded image format.
A host may disable WebP, bypass PNG re-encoding or explicitly opt into lossy
WebP/palette PNG. It must publish with the correct extension and actual receipt.
There is no new image publisher, file watcher, optimizer subprocess or global
resource configuration. Browser CI keeps its two workers.

Local corpus observation (2026-11-05): 38 existing repository PNGs totalled
15,313,994 bytes. Default lossless PNG retained 15,010,083 bytes (1.98% reduction);
lossless WebP produced 7,874,400 bytes (48.58% reduction). RGBA decode comparison
was identical for every original/WebP pair in this corpus. Explicit palette PNG
(quality 95, effort 7) produced 6,002,680 bytes (60.80% reduction), with a nonzero
mean absolute channel error; it must not be described as lossless. Ordered local
encoding totals were 10.61/19.28/14.10 seconds respectively, not an isolated or
cross-platform throughput benchmark. Source images were not replaced in-place.
These results guide a per-image choice, not a universal WebP or PNG preference.

Controls cover exact RGBA/dimensions/partial-alpha preservation, original retention
when PNG grows, explicit codec bypass, invalid/corrupted inputs, lossy opt-in,
real browser/region hashes and MIME/byte selection. SVG remains a separate vector
output: embedded fonts and zoom semantics make bytes alone an insufficient reason
to replace it. Lossless WebP may canonicalize invisible colour under alpha zero;
no pixel-perfect hidden-colour guarantee is inferred beyond the measured corpus.
