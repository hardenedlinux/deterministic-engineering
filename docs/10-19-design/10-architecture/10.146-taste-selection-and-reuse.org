#+title: 10.146 Taste selection, source observations and REUSE

* Responsibility and calls
10.145 post-export inspection remains useful, but cannot choose a composition.
selectTaste(input, policies) now precedes composeFigure and exportFigure.
Question subjectRefs/relationRefs bind to the existing captured model; selected
source projections bind to captured sourceRef and exact excerpt. Generic pure
policies choose focal subjects, optional graph scope, existing ELK direction and
open visual roles. Model labels, mandatory subjects/relations, source bytes and
intent cannot be rewritten by a selection. No new solver or model is introduced.

The source declaration selects Questions and evidence per variant. The same
program handles adopter, maintainer and source-gap, including unseen Questions
and renamed identities. These are changed inputs, not three hardcoded recipes.
Required fidelity and explicit group boundaries remain retained. Missing source
observations appear in measured node content, avoiding a color-only distinction.
Architecture and Workflow remain separate views. README uses sketchbook throughout.

* Trust and invalidation
An EvidenceProjection is a declared, source-bound display observation. Its state
is not a verifier receipt, C/Q/R, authenticated execution or authorization.
Supported never grants acceptance. Unknown IDs, absent excerpt, unselected refs,
changed input under an old selection, or attempted fidelity removal refuse.
Reselection is explicit. The selection trace carries rule identity, rationale,
Question/subject/source refs and the complete input binding. Post-export review
still checks actual hashes and observations; readability is not aesthetic proof.

* Licensing and generated outputs
Use official REUSE tools and CI, not a parallel license checker. Source headers
use each language's comment syntax; JSON/PNG use standard adjacent .license files.
Existing mixed licenses remain untouched. License texts are shipped with the
render package. Host-supplied export attribution is optional and never assumes
ownership of downstream work. Example publishers supply project and actual
embedded-font notices before HTML/SVG hashes are calculated. Font-free PNGs
retain project attribution through sidecars. Historical exports are historical;
adding notices does not make old source receipts current evidence.
