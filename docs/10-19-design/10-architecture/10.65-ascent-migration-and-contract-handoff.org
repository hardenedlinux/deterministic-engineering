** Target public handoff, without a compatibility facade

Use current generic rules/interface plus explicitly selected declaration exports
for project rule construction. Keep the complete Program, sources, outputs,
bindings, bounds and explanation semantics. make-declared-program reconstructs
relations/rules/bounds/source handles as inspected; do not assume arbitrary custom
Program fields survive that constructor. A custom callback/extension must be
checked against the actual constructor chosen, not promised by a comment.

The project currently consumes exported advanced Clue and ledger leaves. P0 must
make their support level explicit with the Flow owner before installation: qualify
those exact exported leaf APIs as supported Host interfaces, or publish their
capabilities through existing POO objects/funs/interface at that owner. Proposed
ordinary POO operations compose a Host-owned history capability and Agent-limited
exchange capability; they are not another hash/action DSL in this Library. Names
and callable contracts for that POO route remain an upstream publication decision,
not an invented already available API. The leaf source locations above are exact;
the missing facade publication is an explicit gap. No shim at the old ASCENT
Namespace, duplicate ledger/store, copied query rules or silent old-binary fallback.
