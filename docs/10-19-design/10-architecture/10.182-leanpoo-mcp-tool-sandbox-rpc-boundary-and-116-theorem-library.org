* Overview: B11 MCP / Tool-Sandbox & RPC Schema-Boundary Safety
:PROPERTIES:
:CUSTOM_ID: arch10182-overview
:END:

Phase 34 introduces Business Extension **=B11=: Deterministic MCP / Tool-Sandbox
& RPC Schema-Boundary Safety** — defending AI Agent tool-calling interfaces
against the five structural supply-chain and runtime failure modes of modern
MCP/RPC ecosystems:
1. **Unpinned / Shadow Tool Invocation** (blocked via immutable =M1= manifest pinning).
2. **MCP Schema Rug-Pull** (silent mutation of tool descriptions/schemas between approval and execution).
3. **Sandbox Scope Escalation** (filesystem/egress scopes confined by both pinned manifest and the 10th =R3= non-leakable =M3= capability `ToolSandboxCapability`).
4. **Non-Idempotent Side-Effect Replay on Ambiguous RPC Timeout** (side-effecting tools require idempotency keys; ambiguous timeouts enter `PendingUnknownEffect` and block blind retry until explicit =M1= reconciliation).
5. **Response Overflow & Untrusted Output Laundering** (output bytes strictly bounded; every tool response is tagged `UntrustedExternal`, so =B7= CaMeL blocks it from hijacking privileged control slots).
