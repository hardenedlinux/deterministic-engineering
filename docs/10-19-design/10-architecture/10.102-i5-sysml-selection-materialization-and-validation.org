* Scope, verdicts and effect boundary
:PROPERTIES:
:CUSTOM_ID: i5-unified-scope
:END:

This unifies 10.94 with 10.97--10.101. I5 consumes the same original C and actual
accepted inference view, selects a captured supported candidate/plan/catalog/mapping,
materializes an exact bounded SysML candidate bundle, and obtains independent
conformance, language/resolution and property outcomes through their actual owners.
It supplies a reviewable candidate and associated outcomes to I6; it does not promote
them implicitly. Accepted inference, candidate generation, validation and permitted
publication are separate conclusions with separate prerequisites.

#+begin_example
I0 actual load + I1 K1/SD/S1 + I2 real offerings + I3 C + I4 accepted view
 -> checked same-C selection -> resolved identity/name/reference plan
 -> pure candidate bytes -> owned staging of exact root/support/trace
 -> explicit actual validation operation -> independent layered outcomes
 -> current-use checks -> separate explicit I6 request for B -> O
#+end_example

These are target fields/call boundaries, not implemented APIs or executed controls.
This update edits Org/D2 only. No implementation, SysML model, package or directory
reorganization, actual capture/inference/materialization, validator/version command,
acceptance/build/load/cold/recovery run, root publication or automation expansion is
performed. Static document checks and D2 rendering are documentation work only.

Library owns reusable catalog/model/mapping/validation expectations; Profile selects
supported options; Scenario supplies original C and actual view/current-use bindings;
Module owns qualified resolution/serialization operations; actual selected checker/
tool/process and evidence owners own their respective attempts/results. I6 owns the
explicit Project effect and its recovery. Core/POO supply existing value/Scope/source
mechanisms, not a generic model publisher or new validation credential registry.

Keep legitimate supported cyclic references using bounded visited/identity tracking;
closure need not be a tree. Unknown kinds/encoding refuse; genuine observed missing
content may be a typed gap only where policy permits it. Independently demanded
units are not erased by missing nodes/references. Directory/path classification and
reference traversal must fit actual finite limits; a source inventory is not proof
that all implicit loads are known.

Finalize the content inventory after exact candidate/support bytes and before later
validation outcomes. It excludes its own digest and future receipts. Digests check
integrity; they do not issue provenance. C keeps original B/support I; O is an output,
not appended into C. Staging uses owned captured inputs, not hash-then-reopen mutable
originals. Relocation preserves document bases and intended binding; a new output
path must not select a different ancestor project/catalog/library.

During validation, a discovered input must demonstrably belong to the already captured
qualified domain; otherwise record incomplete/drifted attempt and require appropriate
new acquisition. Do not silently extend C. Actual tool-created caches/reports are
separate owned outputs with explicit effects, not new immutable source inputs.
Mandatory Org/decision/D2 products retain independent content-observer obligations;
SysML resolving a source URI does not verify that section's content.
