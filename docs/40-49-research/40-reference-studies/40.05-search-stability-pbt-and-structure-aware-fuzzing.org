* Problem Statement: Why Search & Interactive Search-Box Stability Differs from Resource Aging
:PROPERTIES:
:CUSTOM_ID: study4005-problem
:STATUS: implemented-verified
:END:

Long-running resource stability ([[file:40.04-software-aging-and-steady-state-stability.org][40.04]], =SM1=–=SM7=) proves that memory,
file descriptors, goroutines/tasks, caches, and render budgets remain conserved
over arbitrary cycles. *Interactive search engines and live search boxes*
(typeahead minibuffers, Emacs Consult/Orderless/Helm overlays, multi-tier
Rust/Scheme workspace search schedulers) fail in *qualitatively different* ways
even when steady-state heap usage is flat:

1. *Asynchronous Query Racing & Selection Identity Drift (=SM8=)*:
   Every keystroke creates a new query generation. Out-of-order RPC delivery,
   non-monotonic cancellation (an older goroutine acquiring the lock after a
   newer keystroke and cancelling the newer request), stale DSL results arriving
   without epoch verification, or a higher-priority source batch inserting rows
   above the user's cursor immediately before =Enter= causes silent wrong-item
   execution, stale UI flashing, or suppressed Follow-Mode previews.
2. *Single-Flight Coordinator Deadlocks Under Async Cancellation (=SM9=)*:
   To avoid =N= concurrent agents or keystrokes triggering =N= disk-sync or
   index-rebuild storms (Dean & Barroso tail-latency amplification), search
   schedulers coalesce concurrent callers onto a single leader via atomic
   =in_flight= flags and =tokio::sync::Notify= / condition variables. Under
   async cancellation (e.g., =timeout= or future =Drop= mid-=.await=), a leader
   without a =Drop= guard leaves =in_flight = true= permanently, deadlocking all
   future searches. Likewise, awaiting =Notify::notified()= without calling
   =.enable()= before double-checking =in_flight= creates a classic lost-wakeup
   deadlock.
3. *Metamorphic Query Algebra, Unicode & Geometry Boundary Bugs (=SM10=)*:
   Search boxes lack a simple single-input oracle ("is this ranked list right?")
   and accept unbounded adversarial UTF-8/DSL/qualifier strings:
   - Axis qualifiers (=@lang:rust=, =@prefix:crates/=, =@ext:rs=) leaking into
     literal text matchers and silently producing *zero matches*.
   - Inconsistent case folding (=strings.ToLower= multi-rune expansion of =İ=
     U+0130 vs. 1-to-1 =unicode.ToLower=) breaking *reflexivity* (a string fails
     to match itself).
   - Last-wins qualifier parsing paired with prepend-only UI scoping
     (=@prefix:new/ @prefix:old/=) causing "Scope to Directory" to silently no-op.
   - Multi-=#= separators injecting literal =#= as an unsatisfiable filter token,
     unbounded clipboard pastes triggering synchronous parse/scan stalls, and
     narrow-viewport clipped tabs still responding to phantom mouse hit-tests.
4. *IPC Half-Open Reconnect & Duplicate Replay Storms (=SM12=)*:
   When a long-lived gRPC/Unix-socket bridge experiences a half-open network
   stall, reconnect loops that open a replacement stream without retiring the
   prior socket/handle accumulate leaked zombie descriptors linearly with outage
   count; in-flight frames from superseded epochs corrupt live state if unfenced,
   and retrying side-effecting RPCs without an idempotency key commits duplicate
   mutations.
5. *Interactive Search-Box IME Composition, Focus-Loss & Shortcut Races (=SM13=)*:
   CJK/dead-key IME input fires =Enter= to commit candidate characters while
   =isComposing= is active (=keyCode === 229=). Unguarded =keydown= submit
   handlers prematurely dispatch raw pinyin/preedit text; focus =blur= during an
   active composition leaves orphaned preedit buffers that block subsequent
   submits; and global single-key/chord shortcuts fire mid-composition and
   corrupt the active candidate session.
6. *Chaos Fault-Injection Recovery Envelopes & Circuit-Breaker Shedding (=SM14=)*:
   Under sustained fault injection (latency spikes, stream resets, partial
   outages — Basiri et al., /Chaos Engineering/, IEEE Software 2016; Nygard,
   /Release It!/), unbounded retries amplify load into metastable collapse. A
   bounded circuit breaker transitions =Closed -> Open -> HalfOpen -> Closed=,
   enforcing a strict retry budget, emitting typed fast-fail refusals with zero
   silent partial drops while open, and recovering cleanly via a single bounded
   half-open probe once faults subside.

:CUSTOM_ID: study4005-literature

Every formal model in =@deterministic-engineering/quint-models= exists as an
*adversarial challenge generator*. Bridging four research lineages closes the
gap between finite-state proofs and real search-box boundary bugs:

* Mandatory Adversarial Pressure Grading Policy (=ADV-L1=–=ADV-L4=)
:PROPERTIES:

formal model, fuzz harness, and downstream verification suite MUST declare and

|------+-------+--------------------------+------------------|

| =ADV-L4= | Hostile Attack / Exploit | Weaponized intermediate/leaf/dangling/chained symlinks, manifest traversal escapes, duplicate tar entry shadowing, non-canonical =./=//= aliases, concatenated multistream gzip, cumulative decompression bombs | *REQUIRED TARGET* for AI-defensive security boundaries & real-repo RED->GREEN exploits |

* Metamorphic Relations Catalog for Interactive Search Boxes (=MR1=–=MR6=)
:PROPERTIES:
:CUSTOM_ID: study4005-metamorphic
:END:

- *MR1 (Unicode Reflexivity)*: For every non-empty printable single-token query
  $t$ without parser sigils (=@=, =#=, =!=, =(=), $t$ MUST match itself under the
  same case-folding semantics used for highlighting.
- *MR2 (Orderless Permutation Invariance)*: For any positive Orderless tokens
  $a, b$ and candidate text $x$, $\mathrm{match}(\text{"}a\ b\text{"}, x) =
  \mathrm{match}(\text{"}b\ a\text{"}, x)$.
- *MR3 (Qualifier Orthogonality)*: Extracting axis qualifiers (=@lang:=,
  =@doc:=, =@prefix:=, =@ext:=, =@sym:=, =@graph:=) MUST NEVER leak qualifier
  literals into the local text matcher; a pure qualifier query without free text
  must match all backend-admitted candidates.
- *MR4 (Negation Anti-Monotonicity & Separator Resilience)*: Adding a negation
  token =!n= satisfies $M(q \cup \{\text{!}n\}) \subseteq M(q)$; repeated stage
  separators (=a # b # c=) MUST NOT inject literal =#= into positive tokens.
- *MR5 (Scope-Replace Determinism & S-Expr Custody)*: Applying a directory or
  language scope action replaces any prior conflicting axis token so the newly
  chosen scope actually takes effect, and never corrupts active S-expression DSL
  queries.
