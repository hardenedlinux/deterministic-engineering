* Navigation by area and category

Documentation follows Johnny.Decimal organization: an area reserves a ten-number
range, a category occupies one two-digit number inside that range, and an item
uses category.item identity such as 20.03. The path carries the area, category and
item; Org headings retain separate stable semantic CUSTOM_ID anchors.

* Numbering and update policy
:PROPERTIES:
:CUSTOM_ID: jd-maintenance
:STATUS: documentation-contract
:END:

- Allocate each new item inside its owning category; expand the category/area only when its responsibility warrants it.
- Keep an assigned item number stable. Do not renumber existing documents merely to change reading order; update this index instead.
- Retired numbers remain reserved in the register. A move to another category records the old/new identity and updates every reference in the same change.
- D2 source and SVG share one item number. They are editable/rendered forms of one view, not independent design authorities.
- Org file properties record JD_ID. CUSTOM_ID, CASE_ID, GW lineage and GAP identities keep their semantic roles and are not replaced by location numbers.
- Update Org links, D2 org-target comments, the item register and generated SVGs together when a path or represented relationship changes.
- README.org remains the conventional repository entry point. It links here and does not duplicate the numbering authority.
- Research checkouts under .data remain local inputs; they are not numbered maintained design documents or runtime dependencies.

Document locations are distinct from external requirement identity. AR05 names a
local case; SWE-088 names a NASA requirement in a selected edition; its criterion
also needs the standard-source identity. Link these meanings through the existing
Aitia Standards/SDLC owner rather than replacing Johnny.Decimal with SWE numbers
or inventing SWE requirements. [[file:../../10-19-design/10-architecture/10.19-standard-identities-and-aitia-review-traceability.org][10.19]] records the ownership and mapping contract.

This organization change preserves existing semantic anchors. The first numbered
layout is the initial publication structure; the former unnumbered layout is not
maintained as a parallel tree. The [[file:../../90-99-views/90-architecture-views/90.01-index.org::#org-d2-contract][paired Org/D2 contract]] supplies the semantic,
rendering and review checks in addition to this location policy.
