* Recorded local setup
:PROPERTIES:
:CUSTOM_ID: local-package-links
:OBSERVED_DATE: 2026-10-18
:STATUS: linked-and-listed-not-import-qualified
:END:

The user-authorized local package links have been created with the installed
Gerbil package manager. Both link commands and the scoped list command exited
zero. The links are local ignored state, not tracked copies of upstream sources.
At this original setup observation, explicit GERBIL_PATH was required because
no root gerbil.pkg existed. The subsequent [[file:00.03-scheme-package-bootstrap.org][00.03 package bootstrap]] added the
root declaration and verified native project-context build/import. The commands
below preserve the original explicit-environment setup record.

#+NAME: local-link-commands
#+begin_src sh :eval never :exports code
env GERBIL_PATH="$PWD/.gerbil" gerbil pkg link github.com/tao3k/poo-flow /Users/guangtao/ghq/github.com/tao3k/poo-flow
env GERBIL_PATH="$PWD/.gerbil" gerbil pkg link github.com/tao3k/poo-flow-core /Users/guangtao/ghq/github.com/tao3k/poo-flow/core
env GERBIL_PATH="$PWD/.gerbil" gerbil pkg list
#+end_src

Run from the repository root. The link commands are creation commands, not
idempotent repair commands: an existing destination must first be inspected.
Never uninstall a Gerbil package workspace to resolve a link or tag conflict.

* Qualification boundary and environment limitation
:PROPERTIES:
:CUSTOM_ID: local-link-boundary
:STATUS: setup-only
:END:

The unscoped global pkg list failed on an unrelated broken
/Users/guangtao/.gerbil/pkg/gslph entry. That entry was left untouched. The explicit
local environment lists both linked packages successfully and avoids changing
global package state. The package manager also prints a std/net/request
deprecation warning; it did not prevent the local link/list commands succeeding.

No dependency install, compiled import, native ABI check, provider realization,
Scenario execution or gateway init was performed. A package source link is not
compiled module resolution. No runtime code, gerbil.pkg or init.ss was added.
Before an eventual import demonstration, capture the chosen live source content
and resolve its declared dependencies under the existing package workflow.
Do not substitute a different pinned revision to make dependency resolution pass.
