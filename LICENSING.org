#+title: Copyright and REUSE

This repository uses REUSE SPDX file-level licensing. The default project license
is LGPL-2.1-or-later, as confirmed by the project owner; the package declaration and file headers
use that same or-later grant. Project-owned copyright notices identify
hardenedlinux Linux Team and Contributors. Third-party font notices retain their
actual authors. See [[file:docs/10-19-design/10-architecture/10.146-taste-selection-and-reuse.org][the provenance audit in 10.146]] for the corrected concurrency
test header; an existing header alone is not evidence of an upstream code origin.

Comment-capable files carry SPDX headers in their own comment syntax. Strict JSON
and binary PNG cannot contain source comments and use adjacent .license files.
License texts are in LICENSES; those canonical texts need no extra header.

Historical D2 exports embedding Source Sans Pro retain Adobe's 2010–2018 notice
and OFL-1.1. Current exports embedding Inter or Kalam retain their respective
notices. SPDX annotations are written before generated HTML/SVG fingerprints;
changing a historical export does not make its old receipt current evidence.

Run the official REUSE CLI: reuse lint. CI runs the official reuse-action.
Do not put blanket override rules over third-party or mixed-license files.
