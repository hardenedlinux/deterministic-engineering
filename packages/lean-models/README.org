* Responsibility Boundary (10.154 / MR01-MR02)

This Lake package (~lean-model-content~) proves *unbounded algebraic laws*,
*arbitrary-depth structural induction*, *LeanPoo contract refinements*
(~LeanPoo.Functional.ObjectContract.refine~), and *dependency-certified cross-patch
proof reuse* (~LeanPoo.Proof.reuse~ / ~LeanPoo.Proof.close~).

It does *not* duplicate finite-state Quint interleavings or countermodels
(owned by ~packages/quint-models/~).
