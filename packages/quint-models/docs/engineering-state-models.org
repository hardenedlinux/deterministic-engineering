* Overview

Beyond security and Zero Trust threat boundaries, Quint is equally effective for
*systems-engineering determinism*: verifying finite-state protocols where crash
reordering, distributed elections, concurrency interleavings, weak-memory
parallel scheduling, or collector barriers can violate safety invariants.

All 13 engineering models live as co-located Scheme POO AST + Quint Yuanxu units
under =packages/quint-models/engineering/<subdomain>/<model>/=, partitioned into
five formal subdomains corresponding to distinct runtime failure classes:

| Subdomain | Yuanxu Mount | Path | Failure Classes Addressed |
|-----------+--------------+------+---------------------------|
| *Storage* | =Quint.Engineering.Storage= | =engineering/storage/= | WAL/ARIES page-cache write reordering, crash data loss, MVCC/SSI write skew (A5B) & lost =SIREAD= locks |
| *Consensus* | =Quint.Engineering.Consensus= | =engineering/consensus/= | Raft §5.4.1 stale-log leader election & §5.4.2 Figure 8 overwrite; BFT =2f+1= quorum intersection & locked-block view-change safety |
| *Concurrency* | =Quint.Engineering.Concurrency= | =engineering/concurrency/= | Backpressure permit leak / overflow, structured-cancellation orphan tasks, stale lease zombie writes, duplicate saga effects |
| *Parallel* | =Quint.Engineering.Parallel= | =engineering/parallel/= | Lock-free EBR premature reclamation, Chase-Lev work-stealing deque lost/duplicate pop, x86-TSO hazard-pointer store-buffer UAF |
| *GC* | =Quint.Engineering.GC= | =engineering/gc/= | Concurrent tri-color missing write barrier (lost live object), mutator/collector safepoint handshake races |

* 1. Storage (=engineering/storage/=)

- *=wal-crash-recovery=* (=WalCrashRecovery.qnt=): models ARIES write-ahead
  logging with volatile page-cache writeback reordering and =fsync= ordering;
  auto-derived countermodels drop WAL-before-page flush or commit =fsync=.
- *=mvcc-ssi-write-skew=* (=MvccSsiWriteSkew.qnt=): models PostgreSQL/Cahill
  Serializable Snapshot Isolation (SSI) with First-Committer-Wins, =SIREAD= lock
  retention across commits, and read-time =rw=-antidependency detection
  (=bound.extended-counterexample=).

* 2. Consensus (=engineering/consensus/=)

- *=raft-leader-commitment=* (=RaftLeaderCommitment.qnt=): models Raft §5.4.1
  up-to-date log election restriction and §5.4.2 Figure 8 current-term
  commitment rule; dropping the current-term guard automatically synthesizes the
  classic 8-step Figure 8 commit-overwrite counterexample
  (=bound.extended-counterexample=).
- *=bft-quorum-lock=* (=BftQuorumLock.qnt=): models PBFT / Tendermint / HotStuff
  Byzantine Fault Tolerant consensus (=n=3f+1=, 3 honest replicas + 1
  equivocating Byzantine replica voting for conflicting values in every round);
  auto-derived countermodels drop =2f+1= quorum intersection, view-change lock
  respect, or lock recording on precommit (=bound.extended-counterexample=).

* 3. Concurrency (=engineering/concurrency/=)

- *=backpressure-memory=* (=BackpressureOwners.qnt=): co-located declarative
  bounded ownership conservation across =queued=, =running=, =returned=, and
  non-abortable =cleanup= buckets; auto-derived countermodels for early permit
  release on cancellation, admission over-capacity, and queue overflow.
- *=structured-cancellation=* (=StructuredCancellation.qnt=): parent-child
  cancellation quiescence preventing fire-and-forget orphan effects.
- *=lease-fencing-token=* (=LeaseFencingToken.qnt=): monotonic fencing token
  guard neutralizing zombie writes from GC-paused lease holders.
- *=saga-compensation-idempotency=* (=SagaCompensationIdempotency.qnt=):
  compensating transactions, idempotency key deduplication under reply loss, and
  durable cancellation tombstones blocking late in-flight retries.

* 4. Parallel (=engineering/parallel/=)

- *=epoch-reclamation=* (=EpochReclamation.qnt=): lock-free Epoch-Based
  Reclamation (EBR) with safe grace-period calculation and premature-reclaim
  countermodel.
- *=work-stealing-deque=* (=WorkStealingDeque.qnt=): Chase-Lev lock-free
  work-stealing deque with owner =push/pop= vs thief =steal= and missing
  last-item CAS countermodel.
- *=hazard-pointers-tso=* (=HazardPointersTso.qnt=): Michael Hazard Pointers
  under explicit x86-TSO per-thread store-buffer reordering; omitting the
  =mfence= before validation automatically synthesizes a 7-step emergent
  Use-After-Free counterexample (=bound.deep-counterexample=).

* 5. Garbage Collection (=engineering/gc/=)

- *=tricolor-write-barrier=* (=TricolorWriteBarrier.qnt=): concurrent tri-color
  marking with Dijkstra insertion write barrier; dropping the barrier yields a
  swept-live-object counterexample.
- *=safepoint-handshake=* (=SafepointHandshake.qnt=): asymmetric
  mutator/collector safepoint handshake preventing stale barrier phases during
  collection transitions.

* Shared Verification Discipline

Every =engineering/= model shares the exact same Yuanxu Design 165 contract as
=threat/= models:

1. Co-located Scheme POO AST (=types.ss=, =objects.ss=, =interface.ss=),
   projected pure =.qnt= with embedded =// @quint-*= verification directives
   (zero JSON sidecars), and auto-projected =README.org=.
2. Emergent relational safety invariants (zero synthetic =unsafe= boolean flags)
   backed by Band-5 monotonic =governance.mandatory-countermodels=.
3. Every declared guard paired with an auto-derived weakened countermodel
   refuted by Apalache =0.62.1= with an inspectable ITF predicate witness.
