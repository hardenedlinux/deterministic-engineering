explicitly inside a countermodel action. While useful for quick sketches,
*gold-standard formal specifications express safety purely as a relational

* 2. Closing the Gap: Quint MBT (=--mbt=) to Go / Rust / TypeScript

Bounded verification proves properties of the *abstract model*, not the concrete
Go or Rust code. Following Informal Systems' Quint Model-Based Testing (MBT)
pattern (=quint-connect=), =@deterministic-engineering/quint-modules-resolver=
exposes =run --mbt --out-itf=...=:

#+begin_src sh
quint-modules-resolver run \
  @deterministic-engineering/quint-models/threat/identity/oauth-token-lifecycle/OAuthTokenLifecycle.qnt \
  --main=oauth_token_lifecycle \
  --mbt --max-steps=12 --max-samples=10 --n-traces=3 --seed=7 \
  --out-itf=.tmp/oauth-mbt.itf.json
#+end_src

Each generated ITF state includes:
- =mbt::actionTaken= — exact action name selected in that transition;
- =mbt::nondetPicks= — exact non-deterministic parameter choices (e.g. =pkceOk=, =nonceOk=, =newScope=);
- =h= — expected post-transition abstract state record.

A downstream conformance test driver (in Go, Rust, or TypeScript) replays every
step in =states[1..N]= against the real implementation (e.g. =AuthManager= +
=CredentialVault=) and asserts step-by-step state refinement, turning the
upstream Quint library into an executable specification oracle.

* 3. Cross-Engine Differential Equivalence (Scheme =gerbil-parser= vs TS =@informalsystems/quint=)

Upstream DE maintains two independent pure-=.qnt= structural overlay composers:
1. *Gerbil Scheme (=library/quint-methods/grammar.ss=)*: source-preserving LR
   CST walker and verified =SpanEdit= rewriter (=quint-span-compose-overlay=),
   zero Node/Bun dependency.
2. *TypeScript (=packages/quint-modules-resolver/src/compose.ts=)*: AST composer
   built directly on Informal Systems' =@informalsystems/quint= Phase-1 parser.

=packages/quint-modules-resolver/test/differential-compose.test.ts= executes
both composers over identical base + overlay pairs and asserts 3-level
equivalence: (a) =quint typecheck= acceptance, (b) identical deterministic
=quint test --seed=7= passing counts, (c) identical Apalache =quint verify=
verdicts on both safe proofs and intentionally unsafe counterexample overlays,
plus fail-closed refusal parity on type conflicts, missing initializers, and
symbol collisions.
