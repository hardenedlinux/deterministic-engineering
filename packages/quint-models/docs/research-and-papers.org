* Purpose

This index collects the foundational papers, specifications, and technical
references behind =@deterministic-engineering/quint-models=. Each entry is
grouped by modeling domain and linked to the concrete Quint primitives it
informs.

* 1. Specification Languages & Bounded Model Checking (TLA+ / Quint / Apalache)

- *Leslie Lamport (2002)*, /Specifying Systems: The TLA+ Language and Tools for
  Hardware and Software Engineers/, Addison-Wesley.
  - Foundation for action-based state machines, safety/liveness invariants, and
    refinement mappings.
- *Igor Konnov, Jure Kukovec, Thanh-Hai Tran (2019)*, /TLA+ Model Checking Made
  Symbolic/, OOPSLA 2019 (Apalache).
  - Symbolic bounded model checking via SMT (Z3) that underpins our positive
    depth-12 checks and depth-4 ITF counterexample generation.
- *Informal Systems*, /Quint Specification Language/ (=0.33.0=).
  - Modern typed surface syntax over TLA+ semantics with deterministic
    TypeScript simulation and Apalache verification backend.

* 2. Threat-First Modeling, Zero Trust & Capability Security

- *NIST Special Publication 800-207 (2020)*, /Zero Trust Architecture/ (Scott
  Rose, Oliver Borchert, Stu Mitchell, Sean Connelly).
  - Defines PEP/PDP separation, continuous per-request verification, and
    assume-breach posture mapped in [[file:zero-trust-and-state-layers.org][Zero Trust and State Layers]].
- *Rory Ward & Betsy Beyer (2014)*, /BeyondCorp: A New Approach to Enterprise
  Security/, USENIX ;login:.
  - Separates network location from workload/device authorization — directly
    reflected in =capabilities= (network reachability ≠ credential possession).
- *Mark S. Miller (2006)*, /Robust Composition: Towards a Unified Approach to
  Access Control and Concurrency Control/ (PhD Thesis, Johns Hopkins University).
  - Object-Capability (OCap) security, authority attenuation, and non-ambient
    authority; informs =threat/execution/capabilities= and
    =threat/zero-trust/authority-currentness=.
- *Adam Shostack (2014)*, /Threat Modeling: Designing for Security/, Wiley.
  - Structured threat identification; our framework elevates these from static
    diagrams into executable Quint state machines with mandatory countermodels.
- *Daniel Fett, Ralf Küsters, Guido Schmitz (2016)*, /A Comprehensive Formal
  Security Analysis of OAuth 2.0/, ACM CCS 2016; *Daniel Fett, Pedram Hosseyni,
  Ralf Küsters (2023–2025)*, /Formal Security Analysis of FAPI 2.0 & DPoP (RFC
  9449)/; and *IETF RFC 9700 (2025)*, /Best Current Practice for OAuth 2.0
  Security/.
  - Formalizes OAuth 2.0/2.1 protocol attacks, sender-constrained tokens (DPoP
    =cnf.jkt= + single-use =jti=), and PAR/revocation recovery directly modeled
    in =threat/identity/oauth-token-lifecycle=,
    =threat/identity/oidc-federation=, =threat/identity/device-authorization=,
    =threat/identity/oauth-revocation-recovery=, and
    =threat/protocol/dpop-sender-constrain=.
- *Justin Samuel, Nick Mathewson, Justin Cappos, Roger Dingledine (2010)*,
  /Survivable Key Compromise in Software Update Systems/ (TUF), ACM CCS 2010;
  *Santiago Torres-Arias et al. (2019)*, /in-toto: Providing farm-to-table
  guarantees for bits and bytes/, USENIX Security 2019; and *Zachary Newman et
  al. (2022)*, /Sigstore: Software Signing for Everybody/, ACM CCS 2022.
  - Rollback, indefinite freeze, and mix-and-match metadata defenses modeled
    with emergent invariants in =threat/supply-chain/supply-chain-tuf=.
- *OpenSSF SLSA Specification v1.0 / v1.1 (2023–2025)*, /Supply-chain Levels for
  Software Artifacts/; and *Chris Lamb & Stefano Zacchiroli (2022)*,
  /Reproducible Builds: Increasing the Integrity of Software Supply Chains/,
  IEEE Software 39(2).
  - Non-falsifiable builder-signed provenance, reviewed source-digest binding,
    and independent reproducible rebuild attestation defeating compromised L3
    builder injection modeled in =threat/supply-chain/slsa-hermetic-provenance=.
- *Arnar Birgisson, Joe Gibbs Politz, Úlfar Erlingsson, Ankur Taly, Michael
  Vrable, Mark Lentczner (2014)*, /Macaroons: Cookies with Contextual Caveats
  for Decentralized Authorization in the Cloud/, NDSS 2014.
  - Monotonic multi-hop caveat attenuation and chained HMAC integrity for
    agent-to-subagent delegation modeled in
    =threat/protocol/macaroon-delegation-chain=.
- *Edoardo Debenedetti, Ilia Shumailov, Nicholas Carlini, Florian Tramèr et al.
  (2025)*, /Defeating Prompt Injections by Design/ (CaMeL, Google DeepMind & ETH
  Zurich, arXiv:2503.18813).
  - Separates privileged control flow from quarantined untrusted data flow and
    tracks capability-based provenance; directly informs
    =threat/execution/agent-ifc-capability=.
- *Manuel Costa, Boris Köpf, Aashish Kolluri, Andrew Paverd, Mark Russinovich et
  al. (2025)*, /Securing AI Agents with Information-Flow Control/ (FIDES,
  Microsoft Research, NeurIPS 2025, arXiv:2505.23643).
  - Confidentiality/integrity lattice labels and deterministic policy
    enforcement outside the LLM reasoning loop; directly informs
    =threat/execution/agent-ifc-capability=.
- *Manuel Barbosa, Alexandra Boldyreva, Shan Chen, Bogdan Warinschi (2021)*,
  /Provable Security Analysis of FIDO2/, CRYPTO 2021; *Charlie Jacomme & Steve
  Kremer (2021)*, /An Extensive Formal Analysis of Multi-Factor Authentication
  Protocols/, ACM TOPS / IEEE CSF; and *W3C WebAuthn Level 3*.
  - Formalizes RP-ID origin binding against MitM phishing proxies, single-use
    ceremony challenges, and monotonic =signCount= roaming-authenticator clone
    detection; directly informs =threat/identity/webauthn-passkey-ceremony=.
- *IETF RFC 9162 (2021)*, /Certificate Transparency Version 2.0/ (§2.1.4
  Consistency Proofs); *Laurent Chuat, Pawel Szalachowski, Adrian Perrig, Ben
  Laurie, Eran Messeri (2015)*, /Efficient Gossip Protocols for Verifying the
  Consistency of Certificate Logs/, IEEE CNS / NDSS; and *Sigstore Rekor /
  Omniwitness*.
  - Demonstrates why inclusion proofs alone cannot stop a compromised log from
    serving a forked split-view tree and why STH consistency gossip is mandatory;
    directly informs =threat/supply-chain/transparency-log-gossip=.
- *Andreas Haas, Andreas Rossberg, Derek L. Schuff, Ben L. Titzer et al. (2017)*,
  /Bringing the Web up to Speed with WebAssembly/, PLDI 2017; *Shravan Narayan
  et al. (2020)*, /Retrofitting Fine Grain Isolation in the Firefox Renderer/
  (RLBox), USENIX Security 2020; and *WASI Preview 2 / Linux =openat2(RESOLVE_BENEATH)=*.
  - Linear-memory bounds checking, non-ambient capability handle tables, and
    preopened root confinement against path traversal directly modeled in
    =threat/execution/wasm-sandbox-confinement=.
- *Eric Rescorla (2018)*, /IETF RFC 8446: The Transport Layer Security (TLS)
  Protocol Version 1.3/ (§2.3, §8, Appendix E.5) & *IETF RFC 8470*
  (=Early-Data= / =425 Too Early=); *Cas Cremers, Marko Horvat, Jonathan
  Hoyland, Sam Scott, Thyla van der Merwe (2017)*, /A Comprehensive Symbolic
  Analysis of TLS 1.3/, ACM CCS 2017; *Karthikeyan Bhargavan, Bruno Blanchet,
  Nadim Kobeissi (2017)*, /Verified Models and Reference Implementations for the
  TLS 1.3 Standard Candidate/, IEEE S&P 2017; *Marc Fischlin & Felix Günther
  (2017)*, /Replay Attacks on Zero Round-Trip Time/, IEEE EuroS&P 2017; and
  *Trevor Perrin (2018)*, /The Noise Protocol Framework/.
  - Non-idempotent 0-RTT exclusion, multi-node cross-edge strike-register
    replication against replay, and ephemeral (EC)DHE forward secrecy against
    retroactive long-term PSK/STEK compromise directly modeled in
    =threat/protocol/tls13-0rtt-forward-secrecy=.
- *Richard Barnes, Benjamin Beurdouche, Raphael Robert, Jon Millican, Emad
  Omara, Katriel Cohn-Gordon (IETF RFC 9420, 2023)*, /The Messaging Layer
  Security (MLS) Protocol/; *Joël Alwen, Sandro Coretti, Yevgeniy Dodis, Yiannis
  Tselekounis (2020)*, /Security Analysis and Improvements for the IETF MLS
  Standard for Group Messaging/, CRYPTO 2020; and *Katriel Cohn-Gordon, Cas
  Cremers, Benjamin Dowling, Luke Garratt, Douglas Stebila (2017 / 2020)*, /A
  Formal Security Analysis of the Signal Messaging Protocol/, IEEE EuroS&P / JoC.
  - Epoch-key zeroization (Forward Secrecy), fresh-entropy TreeKEM commit
    healing (Post-Compromise Security), and mandatory epoch rotation on member
    removal modeled in =threat/protocol/mls-ratchet-pcs=.

* 3. Exact-Effect Handoff, Durability & Rollback Resistance

- *Pat Helland (2007 / 2016)*, /Life Beyond Distributed Transactions: An
  Apostate's Opinion/, CIDR.
  - Idempotence, uncertain outcomes (=unknown=), and why retries across
    uncertain boundaries cannot assume prior non-execution.
- *Hector Garcia-Molina & Kenneth Salem (1987)*, /Sagas/, ACM SIGMOD.
  - Multi-step effect coordination and compensating/containment boundaries;
    informs =threat/execution/effect-handoff= and
    =threat/execution/effect-containment=.
- *Marcos K. Aguilera et al. / State Rollback Literature*:
  - Distinguishes pure-state consumption from monotonic persistent storage
    (rollback attacks against crash-recovery snapshots); directly modeled in
    =threat/execution/state-rollback=.

* 4. Concurrency & Parallel Runtime Verification

- *David Chase & Yossi Lev (2005)*, /Dynamic Circular Work-Stealing Deque/,
  SPAA 2005; and *Nhat Minh Lê et al. (2013)*, /Correct and Efficient
  Work-Stealing for Weak Memory Models/, PPoPP 2013.
  - Basis for =engineering/parallel/work-stealing-deque=.
- *Keir Fraser (2004)*, /Practical Lock-Freedom/ (PhD Thesis, Cambridge) &
  *Thomas E. Hart et al. (2007)*, /Performance of Memory Reclamation for
  Lockless Synchronization/, JPDC.
  - Epoch-Based Reclamation (EBR) and safe memory reclamation invariants.
- *Maged M. Michael (2004)*, /Hazard Pointers: Safe Memory Reclamation for
  Lock-Free Objects/, IEEE TPDS 15(6); and *Peter Sewell, Susmit Sarkar, Scott
  Owens, Francesco Zappa Nardelli, Magnus O. Myreen (2010)*, /x86-TSO: A
  Rigorous and Usable Programmer's Model for x86 Multiprocessors/, CACM 53(7).
  - Explicit per-thread TSO store-buffer reordering and mandatory =mfence=
    before validation; omitting the fence yields a genuine 7-step emergent
    Use-After-Free counterexample in =engineering/parallel/hazard-pointers-tso=.
- *Backpressure & Bounded Ownership*:
  - Informed by reactive-streams / bounded-queue flow control and realized in
    =engineering/concurrency/backpressure-memory=.
- *Martin Kleppmann (2016)*, /How to do distributed locking/; *Mike Burrows
  (2006)*, /The Chubby lock service for loosely-coupled distributed systems/,
  OSDI 2006; and *Diego Ongaro & John Ousterhout (2014)*, /In Search of an
  Understandable Consensus Algorithm/ (Raft), USENIX ATC 2014.
  - Monotonic fencing tokens neutralizing zombie writes from paused lease
    holders; directly modeled in =engineering/concurrency/lease-fencing-token=.
  - Raft §5.4.1 up-to-date log election restriction and §5.4.2 Figure 8
    current-term commitment rule (automatically synthesizing the classic 8-step
    Figure 8 commit-overwrite counterexample when omitted) directly modeled in
    =engineering/consensus/raft-leader-commitment=.
- *Miguel Castro & Barbara Liskov (1999)*, /Practical Byzantine Fault
  Tolerance/ (PBFT), USENIX OSDI 1999; *Ethan Buchman, Jae Kwon, Zarko
  Milosevic (2018)*, /The latest gossip on BFT consensus/ (Tendermint /
  CometBFT); and *Maofan Yin, Dahlia Malkhi, Michael K. Reiter, Guy Golan
  Gueta, Ittai Abraham (2019)*, /HotStuff: BFT Consensus with Linearity and
  Responsiveness/, ACM PODC 2019.
  - Byzantine =2f+1= quorum intersection under equivocating replicas, precommit
    lock recording, and view-change lock respect modeled in
    =engineering/consensus/bft-quorum-lock=.
  - Saga compensating transactions, idempotency key deduplication under reply
    loss, and durable cancellation tombstones blocking late in-flight retries
    modeled in =engineering/concurrency/saga-compensation-idempotency=.

* 5. Garbage Collection & Memory-Barrier Verification

- *Edsger W. Dijkstra, Leslie Lamport, A. J. Martin, C. S. Scholten, E. F. M.
  Steffens (1978)*, /On-the-Fly Garbage Collection: An Exercise in Cooperation/,
  CACM 21(11).
  - Original tri-color abstraction and insertion write-barrier invariant.
- *Taichi Yuasa (1990)*, /Real-Time Garbage Collection on General-Purpose
  Machines/, Journal of Systems and Software.
  - Snapshot-at-the-Beginning (SATB) deletion barrier and weak tri-color
    invariant.
- *Damien Doligez & Xavier Leroy (1993)*, /A Concurrent, Generational Garbage
  Collector for a Multithreaded Implementation of ML/, POPL 1993; and *Damien
  Doligez & Georges Gonthier (1994)*, /Portable, Unobtrusive Garbage Collection
  for Multiprocessor Systems/, POPL 1994.
  - Formal handshake protocols between mutators and collector across GC phases.
- *Richard Jones, Antony Hosking, Eliot Moss (2023)*, /The Garbage Collection
  Handbook: The Art of Automatic Memory Management/ (2nd ed.), CRC Press.
  - Comprehensive taxonomy of concurrent marking, barriers, and safepoints used
    to structure =engineering/gc/=.

* 6. Storage Crash Consistency & Write-Ahead Logging

- *C. Mohan, Don Haderle, Bruce Lindsay, Hamid Pirahesh, Peter Schwarz (1992)*,
  /ARIES: A Transaction Recovery Method Supporting Fine-Granularity Locking and
  Partial Rollbacks Using Write-Ahead Logging/, ACM TODS 17(1).
  - Canonical Write-Ahead Logging rule: redo/undo log records must reach stable
    storage before dirty in-place data pages are flushed to disk.
- *Thanumalayan Sankaranarayana Pillai, Vijay Chidambaram, Ramnatthan Alagappan,
  Samer Al-Kiswany, Andrea C. Arpaci-Dusseau, Remzi H. Arpaci-Dusseau (2014)*,
  /All File Systems Are Not Created Equal: On the Complexity of Crafting
  Crash-Consistent Applications/, USENIX OSDI 2014 (BOB / ALICE); and *James
  Bornholt et al. (2016)*, /Specifying and Checking File System Crash-Consistency
  Models/, ASPLOS 2016.
  - Formalizes out-of-order OS page-cache writeback and missing-=fsync= commit
    loss anomalies directly modeled in =engineering/storage/wal-crash-recovery=.
- *Hal Berenson, Phil Bernstein, Jim Gray, Jim Melton, Elizabeth O'Neil,
  Patrick O'Neil (1995)*, /A Critique of ANSI SQL Isolation Levels/, ACM SIGMOD
  1995; *Atul Adya, Barbara Liskov, Patrick O'Neil (2000)*, /Generalized
  Isolation Level Definitions/, ICDE 2000; *Michael J. Cahill, Uwe Röhm, Alan D.
  Fekete (2008 / 2009)*, /Serializable Isolation for Snapshot Databases/, ACM
  SIGMOD 2008 / ACM TODS 2009; and *Dan R. K. Ports & Kevin Grittner (2012)*,
  /Serializable Snapshot Isolation in PostgreSQL/, PVLDB 2012.
  - Formalizes Snapshot Isolation Write Skew (A5B), First-Committer-Wins lost
    update conservation, dangerous =rw=-antidependency cycles, post-commit
    =SIREAD= lock retention (§2.2), and read-time =rw=-conflict detection (§3.2)
    directly modeled in =engineering/storage/mvcc-ssi-write-skew=.
