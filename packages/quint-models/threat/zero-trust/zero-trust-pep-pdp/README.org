* Emergent Safety Invariant

PEP enforces an effect only when the PDP decision matches the current policy epoch and active non-revoked subject standing.

#+begin_src quint
val safety = (h.executed == 0 or (h.lastEnforcedEpoch == h.lastEnforcedPolicyEpoch and h.lastEnforcedAllowed and not(h.lastEnforcedRevoked)))
#+end_src
