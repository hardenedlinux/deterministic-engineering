* Emergent Safety Invariant

An action executes only with a distinct approver (approver != proposer) and zero active forbid vetoes.

#+begin_src quint
val safety = (not(h.executed) or (h.proposer > 0 and h.approver > 0 and h.approver != h.proposer and not(h.vetoed)))
#+end_src
