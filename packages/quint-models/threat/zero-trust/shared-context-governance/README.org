* Emergent Safety Invariant

Private context never leaks to peer principals, only owners with explicit declassification may widen private scope, revoked members never read via stale handles, and tainted multi-party shared context never drives tool execution without human gate approval.

#+begin_src quint
val safety = (not(h.privateLeak) and not(h.unauthorizedPromote) and not(h.revokedReadLeak) and not(h.taintedToolHijack))
#+end_src
