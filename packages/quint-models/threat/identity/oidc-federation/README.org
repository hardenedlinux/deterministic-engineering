* Emergent Safety Invariant

Admitted OIDC sessions require asymmetric ID-token verification, matching azp on multi-audience tokens, exact UserInfo sub equality with the verified ID token, and bounded JWKS refresh cooldown.

#+begin_src quint
val safety = ((not(h.admitted) or (h.idTokenVerified and h.userInfoSub == h.idTokenSub and (not(h.multiAud) or h.azpMatchesClient))) and h.jwksRefreshes <= 2)
#+end_src
