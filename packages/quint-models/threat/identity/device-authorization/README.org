* Emergent Safety Invariant

Device authorization never admits a cancelled or expired flow, and Bearer token attachment strictly binds to the authorized ticket account even across active-account switches.

#+begin_src quint
val safety = ((not(h.admitted) or (not(h.deviceCancelled) and not(h.deviceExpired))) and (h.attachedTokenAccount == 0 or h.attachedTokenAccount == h.ticketAccount))
#+end_src
