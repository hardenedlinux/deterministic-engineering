* Overview

This subdomain groups co-located formal threat models for cryptographic
binding, delegation chains, and transport anti-replay / forward-secrecy
protocols: OAuth 2.0 DPoP sender-constrain, Macaroons multi-hop caveat
attenuation, and TLS 1.3 / Noise 0-RTT anti-replay & ECDHE forward secrecy.
