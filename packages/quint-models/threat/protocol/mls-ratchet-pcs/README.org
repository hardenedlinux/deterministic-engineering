* Emergent Safety Invariant

A later state compromise never decrypts past epoch messages (Forward Secrecy), an honest fresh-entropy ratchet heals confidentiality after compromise (PCS), and a removed member never decrypts post-removal epoch messages.

#+begin_src quint
val safety = (not(h.pastMsgDecrypted) and not(h.postHealMsgDecrypted) and not(h.removedMemberDecrypted))
#+end_src
