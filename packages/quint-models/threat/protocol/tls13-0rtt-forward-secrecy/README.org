* Emergent Safety Invariant

Non-idempotent operations never execute in 0-RTT, total 0-RTT executions never exceed genuine client transmissions across edge nodes, and later long-term PSK/STEK compromise never recovers previously exchanged confidential secrets.

#+begin_src quint
val safety = (h.nonIdempotentZeroRttExecutions == 0 and h.zeroRttExecutions <= h.clientSentZeroRtt and not(h.secretRecovered))
#+end_src
