* Emergent Safety Invariant

An attacker who steals a sender-constrained access token never gets accepted at the resource server, and no DPoP proof jti is accepted twice.

#+begin_src quint
val safety = (not(h.acceptedActors.contains(2)) and h.totalAccepted == size(h.usedJtis))
#+end_src
