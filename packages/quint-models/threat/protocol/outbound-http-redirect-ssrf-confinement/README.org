* Emergent Safety Invariant

Under ADV-L4 hostile HTTP/redirect/SSRF inputs, authenticated and origin-pinned HTTP clients never follow unchecked redirects (redirectLeaks == 0), never send remote Bearer credentials or downgrade HTTPS endpoints to cleartext HTTP (schemeDowngrades == 0), reject cross-origin/metadata DownloadURL SSRF (ssrfCrossOriginHits == 0), and block URL userinfo smuggling and symlink HTTP file disclosure (userinfoSmuggles == 0 and symlinkServeLeaks == 0).

* Grounded Papers & Specifications

- *OWASP SSRF Prevention & CWE-918 / CWE-601*: Default HTTP client redirect following silently bypasses initial URL allowlists, downgrades HTTPS to HTTP, and exfiltrates POST bodies or credentials to loopback/cloud-metadata services.
- *RFC 9110 Section 15.4 & RFC 6750 Bearer Token Usage*: Bearer credentials MUST NOT be transmitted over cleartext HTTP to non-loopback hosts, and 301/302/307/308 redirects must be fail-closed on authenticated or origin-pinned clients.
- *CWE-59 / CWE-22 Symlink Following in Static HTTP File Handlers*: Static file handlers that validate paths with os.Stat before ServeFile follow symlinks planted inside served directories and leak arbitrary host files.
