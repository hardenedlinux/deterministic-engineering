* Emergent Safety Invariant

Tool execution effects never commit while the circuit breaker is tripped or via a pre-trip stale lease after re-arm, AI agents never self-rearm a tripped breaker, and execution never exceeds the armed budget cap.

#+begin_src quint
val safety = (not(h.execWhileTripped) and not(h.staleLeaseCommit) and not(h.agentSelfRearmed) and not(h.budgetOverrun) and h.budgetUsed <= 1)
#+end_src
