* Emergent Safety Invariant

Under ADV-L4 hostile inputs, sandbox file writes never traverse symlinks outside canonical root (symlinkEscapes == 0), manifest entry paths stay confined beneath staging root (traversalEscapes == 0), verified archives reject duplicate or non-canonical alias entries (duplicateShadows == 0), and cumulative decompressed bytes never exceed maxDecompressed (decompressionOverruns == 0).

#+end_src

* Grounded Papers & Specifications

- *Linux openat2(2) RESOLVE_BENEATH / RESOLVE_NO_SYMLINKS (2020)*: Lexical relative-path checks alone are defeated by intermediate directory or leaf symlinks; every traversed ancestor must remain confined inside canonical root.
- *Snyk Zip Slip / CVE-2018-1002200 & Archive Ambiguity Research*: Untrusted manifest entry paths and duplicate or non-canonical archive member paths (./, //, shadowing) bypass naive extraction and signature verifiers.
- *D. Fifield (USENIX WOOT 2019)*: A Better Zip Bomb — single-entry size checks fail against multi-entry or multistream decompression bombs without cumulative decompressed byte caps.
