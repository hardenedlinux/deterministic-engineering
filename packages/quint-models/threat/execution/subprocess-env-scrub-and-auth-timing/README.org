* Emergent Safety Invariant

* Grounded Papers & Specifications

- *CWE-526 / CWE-200 Exposure of Sensitive Information Through Environmental Variables*: Spawning untrusted AI tool or plugin-build subprocesses with inherited os.Environ()/std::env::vars() leaks LLM API keys, cloud credentials, and bridge tokens directly to child code.
- *Miller (2006) Robust Composition & Principle of Least Authority (POLA)*: Untrusted child processes MUST start from an empty environment populated strictly via an explicit safe-toolchain allowlist (default-deny) with null stdin isolation.
- *CWE-208 Observable Timing Discrepancy & RFC 6750 Bearer Token Verification*: Short-circuit string equality (`==`) on Bearer authorization headers leaks token prefix timing side channels and fails open on blank expected tokens unless constant-time full-length comparison and non-empty guards are enforced.
