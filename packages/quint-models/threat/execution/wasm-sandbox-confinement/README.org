* Emergent Safety Invariant

A sandboxed guest module never accesses memory beyond guestMemSize, never invokes ungranted host handles, and never escapes its preopened directory root.

#+begin_src quint
val safety = (h.maxAccessedAddr < h.guestMemSize and h.usedHandles.subseteq(h.grantedHandles) and not(h.hostRootEscaped))
#+end_src
