No GitOps read or working-copy provider subprocess inherits GIT_CONFIG_GLOBAL/SYSTEM/EXEC_PATH/SSH_COMMAND overrides (envHijackBreaches == 0 and envConfinementEnforced), every Git and Worktrunk invocation enforces core.hooksPath=/dev/null and core.fsmonitor=false (fsmonitorHookBreaches == 0 and fsmonitorHooksDisabled), projected branch/base_ref/id tokens reject leading '-' and control chars while retention snapshots stay strictly confined inside snapshot_root and Worktrunk receipts reject '/' or '..' (argOrSnapshotBreaches == 0 and argAndSnapshotValidated), and provider commands run bounded with timeout/kill_on_drop while isolate_parallel isolates worker panics into rejected receipts (subprocessOrPanicBreaches == 0 and boundedSubprocessEnforced).
