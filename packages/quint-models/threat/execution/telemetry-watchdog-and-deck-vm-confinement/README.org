* Emergent Safety Invariant

OTLP export enforces remote HTTPS with loopback-only HTTP and clean labels (otlpExfilBreaches == 0 and otlpTlsEnforced), host observer sidecars scrub ambient env via env_clear() and reject symlinked parents (observerEnvBreaches == 0 and observerEnvScrubbed), watchdog clocks reject future/zero timestamps and zero PID/timeout (watchdogBlindBreaches == 0 and watchdogClockBounded), and Deck single-VM active modules, timers, and delays remain strictly bounded (deckVmExhaustionBreaches == 0 and deckVmBoundsEnforced and activeModules >= 1 and activeModules <= 12 and activeTimers >= 0 and activeTimers <= 12).
