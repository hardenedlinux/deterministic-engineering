* Emergent Safety Invariant

Untrusted data-plane content never steers privileged tool control flow, and confidential data never exits to an untrusted sink without explicit declassification.

#+begin_src quint
val safety = (not(h.toolInvoked) or (not(h.toolControlledByTainted) and (not(h.sinkObservedSecret) or h.sinkObservedDeclassified)))
#+end_src
