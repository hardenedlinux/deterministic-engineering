* Emergent Safety Invariant

Monotonic storage prevents replaying a pre-handoff snapshot to emit a second effect.

#+begin_src quint
val safety = (h.sent <= MaxSends and (h.sent == 0 or (h.durable and h.unknown)))
#+end_src
