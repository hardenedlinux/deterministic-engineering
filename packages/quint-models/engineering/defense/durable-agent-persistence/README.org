* Emergent Safety Invariant

Frozen M1 Merkle history stays intact, no M3 root commit occurs without pre-commit stability (unsafeUnstableCommits == 0), no resumed effect runs under stale/revoked authority (unsafeZombieEffects == 0), and no crash replay duplicates an unresolved in-flight intent (duplicateCrashEffects == 0).
