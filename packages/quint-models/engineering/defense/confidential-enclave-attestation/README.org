* Emergent Safety Invariant

Production M3 key release requires debug-mode lockout (debugLeakViolations == 0), measured binary parity (measurementViolations == 0), and TCB SVN floor plus fresh challenge nonce (tcbOrNonceViolations == 0).

#+begin_src quint
val safety = (h.debugLeakViolations == 0 and h.measurementViolations == 0 and h.tcbOrNonceViolations == 0)
#+end_src
