* Emergent Safety Invariant

No suspended agent resumes with a stale approval after baseline drift, policy upgrade, or TTL expiry (staleExecutions == 0), no human-vetoed or already-consumed approval executes (vetoOrReplayViolations == 0 and executedCount <= 1), and no execution resumes from a dirty hibernation that leaked live M3 leases (m3LeakViolations == 0).

#+begin_src quint
val safety = (h.staleExecutions == 0 and h.vetoOrReplayViolations == 0 and h.m3LeakViolations == 0 and h.executedCount <= 1)
#+end_src
