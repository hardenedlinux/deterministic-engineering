* Emergent Safety Invariant

No unverified or untrusted claim enters M1 verified memory (poisonedPromotionViolations == 0), no retracted poisoned claim is re-ingested (repoisoningViolations == 0), and no derived belief lacking a surviving clean justification is read after root retraction (zombieDerivedViolations == 0).

#+begin_src quint

#+end_src
