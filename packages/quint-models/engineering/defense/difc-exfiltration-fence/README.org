No secret-tainted payload flows to a public sink (exfiltrationViolations == 0), no untrusted external input hijacks tool control flow (controlHijackViolations == 0), and no declassification bypasses explicit M3 capability or deterministic redaction sanitization (unauthorizedDeclassViolations == 0).
