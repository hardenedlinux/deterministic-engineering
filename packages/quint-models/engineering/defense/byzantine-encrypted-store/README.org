* Emergent Safety Invariant

Reviewer gold rows stay AEAD-encrypted, no compromised agent leaks gold oracles (oracleLeaks == 0), no tampered/transplanted ciphertext is accepted (forgedVerdicts == 0), and no drifted LLM memo is blindly replayed (driftedReplays == 0).
