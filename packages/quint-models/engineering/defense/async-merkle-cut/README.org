* Emergent Safety Invariant

Asynchronous cuts never drop in-flight cross-agent messages (droppedChannelCuts == 0), concurrent branch conflicts are never erased via last-writer-wins (lwwConflictsErased == 0), and hot policy upgrades never admit verdicts computed under a stale policy digest (stalePolicyAdmits == 0).

#+begin_src quint
val safety = (h.cutConsistent and h.droppedChannelCuts == 0 and h.lwwConflictsErased == 0 and h.stalePolicyAdmits == 0)
#+end_src
