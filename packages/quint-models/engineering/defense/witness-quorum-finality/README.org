* Emergent Safety Invariant

With N=4 witnesses (3 honest + 1 Byzantine double-signer) and threshold t=3 (2f+1), conflicting clean and backdoor branches can never both finalize (not(cleanFinalized and backdoorFinalized)), no honest witness cosigns without RFC 6962 consistency (unverifiedCosignViolations == 0) or double-signs (honestEquivocationViolations == 0), and no checkpoint finalizes below quorum (subQuorumViolations == 0).

#+begin_src quint
val safety = (not((h.cleanFinalized and h.backdoorFinalized)) and h.unverifiedCosignViolations == 0 and h.honestEquivocationViolations == 0 and h.subQuorumViolations == 0)
#+end_src
