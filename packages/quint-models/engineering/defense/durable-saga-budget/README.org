* Emergent Safety Invariant

Linear budget conservation holds (spentBudget + remainingBudget == rootBudget and remainingBudget >= 0), no step executes over budget (budgetViolations == 0) or without a write-ahead compensator (unregisteredCompViolations == 0), and no backward rollback executes past an irreversible pivot or unresolved PendingUnknownEffect (pivotOrUnknownRollbackViolations == 0).

#+begin_src quint
val safety = ((h.spentBudget + h.remainingBudget) == h.rootBudget and h.remainingBudget >= 0 and h.budgetViolations == 0 and h.unregisteredCompViolations == 0 and h.pivotOrUnknownRollbackViolations == 0)
#+end_src

* Explicit Limits

Finite single-compensable-step + single-pivot Saga and integer compute-budget abstraction; does not model arbitrary multi-currency exchange fluctuation, external vendor compensation outage retries beyond idempotency keys, or continuous real-time GPU metering.
