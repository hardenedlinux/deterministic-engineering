* Emergent Safety Invariant

No delegated agent executes with an escalated scope exceeding parent/root (escalationViolations == 0), no downstream delegate executes after any ancestor is revoked in M3 (revokedSubtreeExecutions == 0), and no forged chain MAC, non-delegable hop, or hop-depth overflow executes (forgedOrDepthViolations == 0).

#+begin_src quint
val safety = (h.escalationViolations == 0 and h.revokedSubtreeExecutions == 0 and h.forgedOrDepthViolations == 0)
#+end_src
