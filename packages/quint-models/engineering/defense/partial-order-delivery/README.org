* Emergent Safety Invariant

Every causal event is applied at most once (seq1Applied <= 1 and seq2Applied <= 1), seq2 is never applied out of order before seq1 (outOfOrderApplied == 0), and duplicates/early arrivals are explicitly absorbed or deferred.

#+begin_src quint
val safety = (h.seq1Applied <= 1 and h.seq2Applied <= 1 and h.outOfOrderApplied == 0 and (h.seq2Applied == 0 or h.seq1Applied == 1))
#+end_src
