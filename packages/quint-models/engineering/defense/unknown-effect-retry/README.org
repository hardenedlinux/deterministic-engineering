* Emergent Safety Invariant

Every dispatched effect is authorized at actual consumption time (authorizedDispatches == dispatches), and no non-idempotent effect is dispatched more than once under an unknown remote outcome.

#+begin_src quint
val safety = (h.authorizedDispatches == h.dispatches and h.nonIdempotentDispatches <= 1)
#+end_src
