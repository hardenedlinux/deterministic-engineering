* Emergent Safety Invariant

Serializable Snapshot Isolation preserves the multi-key invariant (balX + balY >= 1) and withdrawal conservation (balX + balY + committedWithdrawals == 2) across all concurrent schedules.

#+begin_src quint
val safety = ((h.balX + h.balY) >= 1 and ((h.balX + h.balY) + h.committedWithdrawals) == 2)
#+end_src

- *M. J. Cahill, U. Rohm & A. D. Fekete (ACM SIGMOD 2008 / TODS 2009)*: Serializable Isolation for Snapshot Databases: SIREAD locks and dangerous rw-structures.
- *D. R. K. Ports & K. Grittner (PVLDB 2012)*: Serializable Snapshot Isolation in PostgreSQL: post-commit SIREAD retention (§2.2) and read-time rw detection (§3.2).

* Explicit Limits

Finite 2-transaction, 2-key MVCC/SSI abstraction verifying write skew, lost updates, persistent SIREAD locks, and read-time rw-antidependencies; does not model 3-txn read-only anomalies, predicate index page coarsening, or GC vacuuming of old SIREAD locks.
