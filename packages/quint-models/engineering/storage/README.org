* Overview

This subdomain groups co-located formal models for durable storage engines,
crash-recovery ordering, and multi-version concurrency control (MVCC). Each
model folder is a self-contained Yuanxu Loader module containing its Scheme POO
AST source (=objects.ss=), sealed contract (=types.ss=), Yuanxu Design 165
interface (=interface.ss=), projected pure =.qnt= specification, and
same-commit verified =README.org=.

* Yuanxu Selection & Reuse

Downstream Gerbil/Yuanxu packages can import *only* this storage subdomain
without loading consensus, GC, or threat models:

#+begin_src scheme
(yuanxu!
  :load-modules (from: :deterministic-engineering/init QuintEngineeringStorageSource)
  mode: auto
  profile: quint.engineering.storage
  mount: Storage
  :profiles (assurance.bounded-proof bound.standard governance.mandatory-countermodels))
#+end_src
