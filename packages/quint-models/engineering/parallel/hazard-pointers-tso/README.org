* Emergent Safety Invariant

A reader thread never dereferences a node that the reclaimer has already freed (zero Use-After-Free under x86-TSO store-buffer reordering).

#+begin_src quint
val safety = not((h.readerPc == 5 and h.nodeFreed))
#+end_src
