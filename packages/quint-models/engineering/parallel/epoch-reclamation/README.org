* Emergent Safety Invariant

A retired shared object is reclaimed only after all pinned workers observe an epoch strictly greater than retiredEpoch, preventing use-after-free.

#+begin_src quint
val safety = (not(h.useAfterFree) and (not(h.freed) or quiescent))
#+end_src
