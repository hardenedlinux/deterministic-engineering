#+TITLE: Engineering Quint Models — Parallelism
#+LANGUAGE: en

This sub-domain hosts finite-state Quint models for parallel scheduling and
lock-free synchronization protocols:

- Chase-Lev work-stealing deque (owner push/pop vs. thief steal + missing-CAS
  countermodel).
- Epoch-Based Reclamation (EBR) safe memory reclamation + premature-advance
  countermodel.
- Bounded parallel worker-pool admission and barrier synchronization.

See [[file:../../docs/engineering-state-models.org][Engineering State Models]] for design rules and verification discipline.
