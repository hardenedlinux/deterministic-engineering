* Overview

This subdomain groups co-located formal models for lock-free memory reclamation,
work-stealing scheduling, and weak memory-model synchronization under x86-TSO.
Each model folder is a self-contained Yuanxu Loader module paired with its
projected pure =.qnt= specification and verified =README.org=.

* Yuanxu Selection & Reuse

#+begin_src scheme
(yuanxu!
  :load-modules (from: :deterministic-engineering/init QuintEngineeringParallelSource)
    mode: auto
    profile: quint.engineering.parallel
    mount: Parallel
    :profiles (assurance.bounded-proof bound.standard governance.mandatory-countermodels)

#+end_src
