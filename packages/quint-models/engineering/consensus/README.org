* Overview

This subdomain groups co-located formal models for replicated state machines and
quorum consensus protocols. Each model directory is a self-contained Yuanxu
Loader module containing its Scheme POO AST source (=objects.ss=), sealed
contract (=types.ss=), Yuanxu Design 165 interface (=interface.ss=), projected
pure =.qnt= specification, and same-commit verified =README.org=.

* Yuanxu Selection & Reuse

Downstream Gerbil/Yuanxu packages can mount only this consensus subdomain:

#+begin_src scheme
(yuanxu!
  :load-modules (from: :deterministic-engineering/init QuintEngineeringConsensusSource)
    mode: auto
    profile: quint.engineering.consensus
    mount: Consensus
    :profiles (assurance.bounded-proof bound.extended-counterexample governance.mandatory-countermodels))
#+end_src
