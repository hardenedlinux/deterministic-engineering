* Emergent Safety Invariant

Byzantine Agreement: despite an equivocating Byzantine replica voting for both conflicting values in every round, two distinct values are never both committed across view changes.

#+begin_src quint
val safety = not((h.committed1 and h.committed2))
#+end_src

* Explicit Limits

Finite 4-replica (3 honest + 1 equivocating Byzantine, n=3f+1) 2-view BFT quorum-intersection, view-monotonicity, and lock-respect abstraction; does not model partial-synchrony liveness, Pacemaker GST timeouts, or BLS threshold signature aggregation.
