* Emergent Safety Invariant

Every search-box mutation path (insertText, pasteYank, setInput) enforces inputBytes <= maxBytes, strips control/ANSI characters (controlLeakCount == 0), keeps editor and query buffer synchronized on valid grapheme cursor boundaries (cursorAligned == true and cursor <= inputBytes), and reclaims oversized buffer capacity on clear.

#+begin_src quint
val safety = (h.inputBytes <= h.maxBytes and h.cursor <= h.inputBytes and h.cursor >= 0 and h.cursorAligned and h.editorSynced and h.capBypassCount == 0 and h.controlLeakCount == 0)
#+end_src
