* Emergent Safety Invariant

Concurrent cold-start opens serialize into at most one authoritative index per workspace root (zero split-brain builds), queries against a switched workspace root never return another root's cached snapshot, cancelling a single-flight query leader re-elects a surviving follower with zero cascade failures, and releasing readers allows tombstone compaction to keep pinnedSegments <= activeReaders + 1.

#+begin_src quint
val safety = (h.activeIndexesForRoot <= 1 and h.splitBrainOpens == 0 and h.crossWorkspaceHits == 0 and h.cascadeFailures == 0 and h.pinnedSegments <= (h.activeReaders + 1) and h.snapshotGen >= 1)
#+end_src

* Grounded Papers & Specifications

- *J. Gray & A. Reuter (1993)*: Transaction Processing: Concepts and Techniques — snapshot isolation prevents readers from observing torn or cross-partition state during incremental compaction.
- *M. Stonebraker & L. Rowe (SIGMOD 1986)*: The Design of Postgres — generational MVCC snapshots bound tombstone retention once readers release old epochs.
- *J. Dean & L. Barroso (CACM 2013)*: The Tail at Scale — single-flight coalescing must isolate per-caller cancellation so one cancelled leader does not cascade-fail healthy followers.
