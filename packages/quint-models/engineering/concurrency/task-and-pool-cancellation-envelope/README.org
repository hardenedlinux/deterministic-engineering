* Emergent Safety Invariant

Cancelling a parent async scope aborts all child tasks (orphanTasks == 0), cancelling an uncommitted DB transaction never returns a poisoned connection to the pool (poisonedPoolConns == 0), and parallel effect batches respect maxConcurrency while preserving exact correlation IDs across worker panics (fanoutBreaches == 0 and lostCorrelationIds == 0).

* Grounded Papers & Specifications

- *N. J. Smith (2018)*: Notes on Structured Concurrency — async scopes must abort all spawned child tasks on cancellation rather than detaching bare JoinHandles.
- *J. Gray & A. Reuter (1993)*: Transaction Processing: Concepts and Techniques — dirty uncommitted transactions cancelled mid-flight must never return poisoned connections to a shared pool.
- *M. Welsh, D. Culler & E. Brewer (ACM SOSP 2001)*: SEDA — bounded concurrency semaphores prevent unbounded parallel task fan-out while caller-owned correlation tables survive worker panics.
