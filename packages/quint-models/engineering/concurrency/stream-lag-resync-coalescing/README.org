* Emergent Safety Invariant

Lagged broadcast subscribers recover cleanly via generation-fenced full-snapshot resync instead of silently terminating the stream, and streaming projection persistence coalesces dirty tokens to prevent per-token write amplification.

#+begin_src quint
val safety = (h.streamAlive and h.clientGen <= h.serverGen and h.dirtyBatch <= 2 and h.uncoalescedFlushes == 0 and (h.lagged or (h.serverGen - h.clientGen) <= 2))
#+end_src
