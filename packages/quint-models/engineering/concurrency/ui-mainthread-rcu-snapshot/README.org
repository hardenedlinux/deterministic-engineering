* Emergent Safety Invariant

The UI render main thread never blocks on a background I/O lock, observes only monotonically published complete snapshot generations (renderGen <= publishedGen), and background staging completes off-lock before atomic swap.

#+begin_src quint
val safety = (not(h.mainStalled) and not(h.writerHoldsLock) and h.renderGen <= h.publishedGen and (not(h.stagingActive) or h.stagingGen > h.publishedGen))
#+end_src
