* Emergent Safety Invariant

Held resources exactly match active work across normal, error, and cancellation exits, returning strictly to zero at quiescence.

#+begin_src quint
val safety = (h.heldHandles == h.activeWork and h.heldHandles <= 2 and (h.activeWork > 0 or h.heldHandles == 0))
#+end_src
