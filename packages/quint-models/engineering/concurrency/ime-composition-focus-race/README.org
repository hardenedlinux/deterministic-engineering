* Emergent Safety Invariant

While an interactive search box is in active IME composition, Enter never triggers premature raw-preedit submission, global shortcuts are suppressed without clobbering candidate selection, and focus loss atomically cancels preedit state leaving zero orphaned compositions.

#+begin_src quint
val safety = (h.prematureSubmits == 0 and h.orphanedCompositions == 0 and h.shortcutCollisions == 0 and (h.focused or (not(h.composing) and h.preeditLen == 0)) and h.submittedGen <= h.committedGen)
#+end_src
