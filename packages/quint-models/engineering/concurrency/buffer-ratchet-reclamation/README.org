* Emergent Safety Invariant

Reusable buffer pools enforce both a per-buffer retain ceiling and a slot ceiling so spike payloads never poison quiescent retained memory.

#+begin_src quint
val safety = (h.pooledSlots <= 1 and h.pooledBytes <= 1 and h.pooledBytes == h.pooledSlots and ((h.activeSmall + h.activeSpike) > 0 or h.pooledBytes <= 1))
#+end_src
