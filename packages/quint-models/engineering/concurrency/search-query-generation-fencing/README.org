* Emergent Safety Invariant

Interactive search generations cancel monotonically without inversion, drop stale out-of-order batches/DSL responses, anchor selection by candidate identity across async batch arrivals, and prune hidden marks on source filtering.

#+begin_src quint
val safety = (h.displayedGen <= h.activeGen and h.markedCount <= h.visibleCount and h.selectedAnchored and not(h.generationInversion) and not(h.staleApplied))
#+end_src
