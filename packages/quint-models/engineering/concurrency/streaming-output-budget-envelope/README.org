* Emergent Safety Invariant

Every incremental stream and HTTP/SSE aggregation path checks textBytes + thinkingBytes + delta <= budgetLimit before buffering, accounts hidden thinking deltas in the same cumulative budget, enforces peakRetainedBytes <= budgetLimit (no check-after-buffering spike), and releases buffered state immediately upon completion or overflow refusal.

#+begin_src quint
val safety = ((h.textBytes + h.thinkingBytes) <= h.budgetLimit and h.peakRetainedBytes <= h.budgetLimit and h.textBytes >= 0 and h.thinkingBytes >= 0 and (h.streamOpen or (h.textBytes == 0 and h.thinkingBytes == 0 and h.streamReleased)) and h.budgetBypassCount == 0)
#+end_src
