* Emergent Safety Invariant

WebView creation never blocks the GPU render thread, hiding a WebView tab always revokes its keyboard focus back to the native frame (not(wvShown) => not(wvFocused)), and Tier-2 untrusted islands never cross into Tier-0 host RPC.

#+begin_src quint
val safety = (not(h.renderBlocked) and (h.wvShown or not(h.wvFocused)) and h.rpcInvokedByTier == 0)
#+end_src
