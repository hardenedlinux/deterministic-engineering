* Emergent Safety Invariant

Mounted UI DOM nodes stay within the bounded viewport window regardless of total transcript length, pending animation frames coalesce to at most one, and per-frame incremental work never exceeds the 120Hz frame budget.

#+begin_src quint
val safety = (h.mountedNodes <= 3 and h.pendingRafs <= 1 and h.frameWorkUnits <= 2)
#+end_src
