* Emergent Safety Invariant

Pending mailbox depth never exceeds 1 via latest-wins coalescing, in-flight workers stay bounded, and committed UI state epoch never regresses behind the highest committed epoch (appliedEpoch == maxAppliedEpoch <= activeEpoch).

#+begin_src quint
val safety = (h.pendingSlots <= 1 and h.inflight <= 2 and h.appliedEpoch == h.maxAppliedEpoch and h.maxAppliedEpoch <= h.activeEpoch)
#+end_src
