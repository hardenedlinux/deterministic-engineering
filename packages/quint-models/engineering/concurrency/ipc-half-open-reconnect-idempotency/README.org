* Emergent Safety Invariant

Reconnecting a half-open IPC/gRPC stream retires the superseded stream so activeStreams stays bounded at 1, replaying a committed idempotency key produces zero duplicate side effects, and late frames from superseded session epochs are fenced and dropped.

#+begin_src quint
val safety = (h.activeStreams <= 1 and h.duplicateEffects == 0 and h.staleFramesApplied == 0 and h.sessionEpoch >= 1)
#+end_src
