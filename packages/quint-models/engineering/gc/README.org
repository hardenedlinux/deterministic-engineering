* Overview

This subdomain groups co-located formal models for concurrent and incremental
garbage collection invariants: tri-color write barriers and mutator/collector
safepoint handshakes. Each model folder is a self-contained Yuanxu Loader module
paired with its projected pure =.qnt= specification and verified =README.org=.

* Yuanxu Selection & Reuse

#+begin_src scheme
(yuanxu!

    mode: auto
    profile: quint.engineering.gc

#+end_src
