* Overview

=@deterministic-engineering/quint-models= is the reusable formal-model library
owned by =hardenedlinux/deterministic-engineering= and distributed as a
read-only =git subtree= mirror.

Every model folder is a self-contained, co-located Yuanxu Loader module pairing
its Gerbil Scheme POO AST source (=objects.ss=), sealed contract (=types.ss=),
Yuanxu Design 165 interface (=interface.ss=), projected pure =.qnt=
specification, and same-commit verified =README.org=.

The library is organized symmetrically into two top-level domains of 5 formal
subdomains each (37 pure =.qnt= models total):

1. *Threat-First Modeling (=threat/<subdomain>/<model>/=)*: 24 security and Zero
   Trust state-machine models across =identity=, =zero-trust=, =protocol=,
   =supply-chain=, and =execution=.
2. *Engineering State Models (=engineering/<subdomain>/<model>/=)*: 13
   deterministic systems-engineering state machines across =storage=,
   =consensus=, =concurrency=, =parallel=, and =gc=.

* Consuming Models

Official =@informalsystems/quint= resolves relative paths only. To import models
from this package using bare package specifiers, pair it with
=@deterministic-engineering/quint-modules-resolver= and pinned
=@informalsystems/quint= (=0.33.0=):

#+begin_src quint
module my_wallet_host {
  import state_rollback(MaxSends = 1).*
    from "@deterministic-engineering/quint-models/threat/execution/state-rollback/StateRollback"
}
#+end_src

Every model directory ships a self-contained pure =.qnt= file with embedded
verification directives (=// @quint-model=, =// @verify=, =// @countermodel=)
alongside its Scheme POO declaration and auto-projected =README.org=. Git commit
integrity owns provenance — no redundant =plan.json= or =receipt.json= sidecars
are committed.

* Limits

These models are finite-state protocol abstractions checked with bounded model
checking (Apalache) and deterministic traces. They do *not* prove cryptography,
compiler/codec correctness, kernel isolation, or physical storage atomicity.
Every model declares its explicit limits in its =// Limits:= header directive.
