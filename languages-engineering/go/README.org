* Ownership

This area owns Go-specific engineering knowledge and future bindings: goroutine
and channel lifecycles, scheduling, memory behavior, implementation cases and
language-specific verification correspondences. No Go implementation or SDK
execution is currently admitted by this directory.

Shared Scheme framework/design drivers remain in =library/drivers/=. A tool
implemented in Go, including OpenSysML, can model other languages and does not
turn every consuming design into Go engineering.
